### ① Check My Understanding

**Question 1 — Objective versus constraint** (pp. 9, 13–14)  
**True or False:** In a model maximizing learning value under a time budget, total learning value is the objective and total time ≤ budget is a constraint.

**My answer:** True. A feasible plan respects the time limit; its quality is measured separately by the objective.  
**AI follow-up:** Does feasibility alone establish optimality?  
**My explanation:** No. Many feasible subsets can have different total values. An optimum must have at least as much value as every other feasible subset in the model.

**Question 2 — Density and indivisible items** (pp. 11, 18, 29–30)  
**True or False:** Selecting whole items by decreasing value/cost always finds an optimal 0/1 knapsack solution.

**My first answer:** True; each unit of capacity buys the greatest value.  
**AI Tutor hint:** Budget 50; items `(value, cost)` are `(60, 10)`, `(100, 20)`, `(120, 30)`. Which items does density take, and what other pair fits?  
**My revised answer:** False. Density takes the first two, value 160 and cost 30; the last no longer fits. The second and third together cost 50 and yield 220.  
**Explanation:** In 0/1 knapsack I cannot take part of the remaining item. The standard density guarantee for fractional knapsack assumes divisible items, positive costs and proportional value, so it does not transfer to indivisible choices.

**Question 3 — Enumerating subsets** (pp. 15–16)  
**True or False:** n distinct available items have 2ⁿ subsets, including the empty subset; independently summing every subset by scanning all n items takes O(n·2ⁿ) time.

**My answer:** True. Each item has two inclusion decisions, and the naïve evaluator checks n decisions for each combination.  
**AI follow-up:** Must we retain all subsets simultaneously?  
**My explanation:** No. We can evaluate one subset at a time and retain the best. Exponential search time does not imply exponential peak memory for every implementation.

**Question 4 — A rejected item** (greedy loop, p. 23)  
**True or False:** While scanning items by priority, if the next item does not fit the remaining budget, the greedy algorithm can stop because every later item also fails to fit.

**My first answer:** True; the best candidate has already been examined.  
**AI Tutor hint:** A value-first ordering encounters `(100, 9)` then `(4, 2)` under budget 2. Does value order imply cost order?  
**My revised answer:** False. Skip the first item and continue; the second fits exactly.  
**Explanation:** Priority and affordability are different properties. The lecture's loop checks every item, using `<=` for feasibility, and does not `break` when one item fails.

**Question 5 — Sorting cost** (pp. 23–24, 27)  
**True or False:** With a constant-time key, sorting n items once and then making a single greedy pass has O(n log n) worst-case time, even though the pass itself is linear.

**My answer:** True. Sorting dominates the O(n) scan.  
**AI follow-up:** Does passing a different function as the sorting key change the whole algorithm?  
**My explanation:** It changes the priority rule while reusing the same feasibility loop. Constant-time keys preserve the bound; an expensive key would need its own cost analysis. Sorting a copied list also preserves the caller's item order.
