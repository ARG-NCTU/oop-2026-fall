### ① Check My Understanding

**Question 1 — Sorting before searching** (pp. 9–10)  
**True or False:** For one membership query on an arbitrary unsorted list, merge sorting first and then binary searching improves the worst-case asymptotic time over linear search.

**My answer:** False. One scan is O(n); preprocessing costs O(n log n) before the O(log n) query.  
**AI follow-up:** What changes if the list stays unchanged and we make K queries?  
**My explanation:** We compare O(Kn) with O(n log n + K log n). Sorting can pay off over many queries. Big O alone does not specify an exact practical break-even point.
