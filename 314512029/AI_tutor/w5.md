### Question 1

**Statement:** If algorithm A is faster than algorithm B on one small input on your computer, A must have a better asymptotic time complexity.

**My answer:** False. Asymptotic time complexity describes how running time grows as the input size becomes large.

**AI feedback:** Correct. A timing result on one small input can reflect constant factors, implementation details, or the computer itself; it does not establish how running time grows.

### Question 2

**Statement:** A linear search that checks a nonempty list from the beginning and stops at the first match has constant best-case time and linear worst-case time in the list length, assuming each comparison takes constant time.

**My answer:** True. Let `n` be the list length. In the best case, the first element matches, requiring one comparison. In the worst case, the target is last or absent, requiring all `n` comparisons.

**AI feedback:** Correct. One comparison is O(1), while checking all `n` elements is O(n), assuming each comparison takes constant time.

### Question 3

**Statement:** If a linear search receives a sorted list and returns `False` as soon as it encounters a value larger than the target, its worst-case time complexity improves from O(n) to O(log n).

**My answer:** False. Early stopping can save comparisons, but the search still checks elements sequentially. Its worst-case time remains O(n).

**AI feedback:** Correct. A target at or beyond the end, or an absent target larger than every list element, forces the algorithm to check all `n` elements. Sorting may improve some executions without changing this sequential algorithm's O(n) worst case.

### Question 4

**Statement:** A program first executes one loop of `n` iterations. It then executes two nested loops that each run `n` times. Because the program contains three loops, its worst-case complexity is O(n³).

**My initial answer:** False. Because the first loop finishes before the nested loops begin, their costs add.

**AI hint:** The addition rule is correct. If the first phase costs O(n), what is the cost of the two nested loops? Add those expressions and keep the fastest-growing term.

**My revised answer:** The first loop takes O(n), and the two nested loops take O(n²). Because the first loop finishes before the nested loops begin, their costs add, giving O(n + n²) = O(n²).

**AI feedback:** Correct. Sequential sections are added, while nested loop costs are multiplied. The quadratic term dominates the linear term as `n` grows.

### Question 5

**Statement:** If an algorithm's exact worst-case operation count is `3n² + 100n + 4`, then saying its worst-case complexity is O(n³) is mathematically valid, although O(n²) is a tighter and more informative bound.

**My answer:** True. The `n²` term dominates as `n` grows, so O(n²) is the tighter upper bound. The tight order of growth is n², which says the operation count is bounded both above and below by constant multiples of n² for sufficiently large n.

**AI feedback:** Correct. O(n³) is a mathematically valid but loose upper bound. The tight order is Θ(n²), because `3n² + 100n + 4` is eventually bounded above and below by positive constant multiples of n².
