## Part A — True / False Questions

### Question 1
**MOOS applications must communicate directly with each other to exchange information.**

**Answer: False**

MOOS applications communicate through MOOSDB using the Publish-Subscribe mechanism. This allows applications to operate independently.

### Question 2
**MOOS-IvP is an open-source C++ framework for autonomous navigation.**

**Answer: True**

MOOS-IvP provides a framework for developing autonomous navigation systems. MOOS handles communication, while IvP supports decision-making.

### Question 3
**The Backseat Driver Architecture separates low-level vehicle control from high-level decision-making.**

**Answer: True**

The Frontseat handles vehicle hardware and low-level control, while the Backseat focuses on autonomous decision-making.

### Question 4
**IvP Helm considers only one behavior when making navigation decisions.**

**Answer: False**

IvP Helm combines utility functions from multiple behaviors to select a suitable overall decision.

### Question 5
**MOOS-IvP and ROS cannot be used together in the same autonomous system.**

**Answer: False**

The lecture introduces the possibility of combining MOOS-IvP and ROS. They can serve different roles within an autonomous system.
