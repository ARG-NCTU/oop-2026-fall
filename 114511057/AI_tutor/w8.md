# Week 8 — Lab07: pybind11 Mini Lab

## 1. What did I learn?

這週主要學習 pybind11，了解如何讓 Python 呼叫 C++ 的函式與類別。以前我不太清楚兩種程式語言可以怎麼一起使用，這次透過實際操作，才知道可以先把 C++ 程式編譯成 Python 模組，再使用 Python 呼叫裡面的功能。

我也學到 `m.def()` 可以將 C++ 函式公開給 Python，而 `py::class_` 則可以綁定 C++ 類別。另外，Python 的 list 也可以透過 pybind11 轉換成 C++ 的 `std::vector`，讓兩種語言可以互相傳遞資料。

## 2. What did I do?

這次先在 Ubuntu WSL 中下載老師提供的 GitHub 專案，依照 README 安裝需要的套件，並建立 Python 虛擬環境。

接著修改 `grade.cpp` 和 `lab.py`，完成三個任務：

- **Task 1：** 完成 `add_bonus()` 函式，計算加分後的成績，並將最高分限制為 100 分。
- **Task 2：** 完成 `average_scores()` 函式，將 Python list 傳入 C++ 計算平均分數，也處理空清單的錯誤情況。
- **Task 3：** 完成 `GradeBook` 類別，讓 Python 可以新增成績、查詢成績筆數以及計算平均。

完成程式修改後，重新編譯 `grade.cpp`，再執行 `python lab.py`，最後成功通過全部三個任務，顯示 `3/3` 關通過。

## 3. Problems I encountered

這次遇到的主要問題是編譯失敗。一開始執行 `python lab.py` 時，出現 `ModuleNotFoundError: No module named 'gradecpp'`，當下不太清楚為什麼 Python 找不到模組。

後來檢查才發現，原本的 `grade.cpp` 沒有成功編譯，因此沒有產生 `.so` 檔案。重新編譯後，又發現程式碼有語法錯誤，例如修改後的程式碼和原本內容黏在一起，以及括號沒有正確配對。

最後重新整理 C++ 程式碼並再次編譯，才順利執行 Python 測試，讓三個任務全部通過。
