# Week 9 — LeetCode 101

## 1. What did I learn?

這週主要學習如何使用 LeetCode 平台進行程式練習，包括搜尋題目、閱讀題目敘述、編寫程式，以及使用 Run 和 Submit 檢查結果。

以前比較少使用 LeetCode，這次才比較清楚整個解題流程，也了解到 Run 和 Submit 的差別。Run 主要是測試目前的案例，而 Submit 則會使用平台的測資進行正式判題。

另外，透過這次的練習，我也複習了 Python 的迴圈、條件判斷和串列操作，並接觸到 Stack（堆疊）的基本概念。

## 2. What did I do?

這次 Lab 我使用 Python3 練習了三道 LeetCode 題目。

第一題是 Two Sum，需要找出陣列中兩個數字相加等於目標值的位置。我使用兩層 for 迴圈，依序檢查不同的數字組合。

第二題是 Best Time to Buy and Sell Stock，需要計算買賣股票可以獲得的最大利潤。我透過記錄最低價格和最大獲利的方式完成程式。

第三題是 Valid Parentheses，需要判斷不同種類的括號是否正確配對。這題使用 Stack，透過加入和移除括號來檢查順序。

完成程式後，我使用 LeetCode 的 Run 功能測試，並學習如何透過 Submit 進行正式判題。

## 3. Problems I encountered

這次遇到的第一個問題是在 Two Sum。剛開始執行程式時出現 Compile Error，後來才發現是因為 LeetCode 的程式語言選錯了，導致 Python 程式無法正常編譯。

另外，剛開始也不太熟悉 LeetCode 的操作介面，不清楚 Run 和 Submit 有什麼不同。

在理解程式方面，Valid Parentheses 的 Stack 概念對我來說比較陌生，需要透過實際範例，才能理解為什麼括號必須按照特定順序配對。

## 4. Reflection

這次 Lab 讓我比較熟悉 LeetCode 的操作，也發現寫程式之前，先看懂題目的輸入、輸出和限制條件很重要。

雖然這次練習的題目都是 Easy，但不同題目需要使用不同的解題方式，不是只要會基本語法就能馬上想到答案。

我覺得自己目前還需要加強獨立思考解題方法的能力，尤其是遇到沒有看過的題目時，希望之後可以先自己嘗試，再透過 AI 協助理解不熟悉的部分。

## 5. AI Tutor Usage

這次主要使用 ChatGPT 協助理解 LeetCode 題目和 Python 程式。

在 Two Sum 中，AI Tutor 先透過簡單的數字範例，幫助我理解 index 的概念，再一步一步說明雙層迴圈的用途。

當程式出現 Compile Error 時，也透過 AI Tutor 找出程式語言設定的問題，並順利完成測試。

在另外兩題中，AI Tutor 提供程式範例並解釋主要的解題邏輯，讓我了解如何計算最大獲利，以及如何使用 Stack 判斷括號是否正確配對。

透過這次練習，我不只學會 LeetCode 的基本操作，也更了解如何利用 AI Tutor 協助自己學習程式設計。
