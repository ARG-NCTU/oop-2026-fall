# W10 AI Tutor 學習紀錄

## 一、本週學習內容

這週的 OOP Lab 主要是在熟悉 LeetCode 平台，練習如何閱讀題目、設計演算法、測試程式並提交答案。這次我使用 Python 3，練習了三道題目，分別是 Two Sum、Valid Parentheses，以及 Best Time to Buy and Sell Stock。

這三題使用不同的解題方法，讓我接觸到 Dictionary、Stack 和 Greedy Algorithm，也更了解如何根據題目的需求選擇適合的資料結構與演算法。

## 二、實作過程

### Task 1：Two Sum

第一題要求從陣列中找出兩個數字，使它們的總和等於指定的 target，並回傳兩個數字的索引。

我使用 Dictionary 記錄已經看過的數字與對應的索引，每次讀取一個新數字，就先計算 `target - num`，確認需要的另一個數字是否已經出現。如果找到，就直接回傳兩個索引。

這種方法不需要使用雙層迴圈，平均時間複雜度為 O(n)，空間複雜度為 O(n)。實際執行後，三個範例測試案例都通過，並顯示 Accepted。

### Task 2：Valid Parentheses

第二題是判斷一串括號是否正確配對，例如 `()[]{}` 是有效的，而 `([)]` 則是無效的。

這題使用 Stack（堆疊）處理。當程式遇到左括號時，就將它放入 Stack；遇到右括號時，則取出最後放入的左括號，確認兩者是否配對。如果括號不符合，或遇到右括號時 Stack 已經是空的，就回傳 False。

最後還需要確認 Stack 是否為空，才能確保所有左括號都有正確配對。這題讓我理解 LIFO（Last In, First Out）的特性，以及為什麼 Stack 適合處理巢狀結構。

時間複雜度為 O(n)，空間複雜度為 O(n)。

### Task 3：Best Time to Buy and Sell Stock

第三題要求從每天的股票價格中，找出只買進一次、賣出一次時可以獲得的最大利潤，而且必須先買進才能賣出。

我使用 Greedy Algorithm，從左到右走訪股價陣列，並使用 `min_price` 記錄目前遇過的最低價格，再計算當天賣出時的利潤，持續更新 `max_profit`。

例如股價為 `[7, 1, 5, 3, 6, 4]`，最佳方式是在價格 1 時買進、價格 6 時賣出，最大利潤為 5。

這個方法只需要走訪陣列一次，因此時間複雜度為 O(n)，而且只使用固定數量的變數，空間複雜度為 O(1)。

## 三、遇到的問題與解決方法

這次主要的挑戰不是程式語法，而是如何從題目要求判斷應該使用哪一種演算法。

例如 Two Sum 一開始很容易想到使用兩層迴圈逐一比較，但透過 Dictionary，就能快速查找需要的另一個數字。Valid Parentheses 則需要考慮括號的先後順序，不能只計算左右括號的數量，因此使用 Stack 會比較適合。

第三題也讓我理解，不需要列舉所有可能的買賣日期，只要持續記錄之前的最低價格，就可以在一次走訪中找到最大利潤。

透過這三題，我開始理解演算法的重點不只是得到正確答案，也包含如何減少不必要的運算。

## 四、AI Tutor 的協助

這次我主要透過 AI Tutor 協助理解題目、選擇演算法，以及說明程式碼的執行邏輯。

AI Tutor 先將每一題的需求轉換成比較容易理解的例子，再提供對應的 Python 程式，並逐步解釋每個變數的用途。

其中對我幫助最大的是理解三種解題方式的差異。Dictionary 適合快速查找已經出現過的資料；Stack 適合處理需要依照相反順序配對的問題；Greedy Algorithm 則可以在特定條件下，透過持續更新局部資訊得到最佳結果。

另外，AI Tutor 也協助我了解 LeetCode 的 Run 和 Submit 差異，讓我知道通過範例測試不代表已經完成正式提交。

## 五、本週心得與反思

這週我覺得最有收穫的是，同樣是處理陣列或字串的題目，解題方式卻可能完全不同。以前寫程式時，我比較習慣先想到能不能用迴圈解決，但這次發現，如果能先理解問題的特性，再選擇適合的資料結構，程式不但可以更簡潔，效率也會比較好。

另外，我也發現時間複雜度和空間複雜度並不是單純的理論，而是能直接用來比較不同解法的效率。例如 Two Sum 使用 Dictionary，以額外的記憶體換取更快的查找速度；而股票買賣問題只需要記錄最低價格和最大利潤，就不需要額外儲存大量資料。

這次練習讓我對演算法的理解比之前更具體，也希望之後遇到新題目時，能先自己思考解題方向，再利用 AI Tutor 檢查與改善，而不是一開始就直接尋找完整答案。
