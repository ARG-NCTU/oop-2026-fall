# W09 AI Tutor 學習紀錄

## 一、本週學習內容

這週的 OOP Lab07 主要是在學習 pybind11，目的是讓 Python 可以直接呼叫 C++ 的函式與類別。這次實驗使用 C++ 實作一個簡單的成績分析工具，再透過 pybind11 將功能提供給 Python 使用。

實驗主要分成三個 Task：

1. **Task 1：基本函式綁定**  
   使用 C++ 實作 `add_bonus()`，計算加分後的成績，並限制最高為 100 分，再透過 `m.def()` 讓 Python 可以呼叫。

2. **Task 2：Python list 與 C++ vector 轉換**  
   使用 `std::vector<double>` 儲存成績，透過 `average_scores()` 計算平均值，並利用 `pybind11/stl.h` 自動轉換 Python 的 list 與 C++ 的 vector。

3. **Task 3：C++ Class 綁定**  
   建立 `GradeBook` 類別，使用 `py::class_` 將建構子與 `add()`、`count()`、`average()` 等方法提供給 Python 使用。

## 二、實作過程

首先，我從 GitHub Clone 老師提供的 `pybind11_mini_lab` 專案，在 WSL 中建立 Python 虛擬環境 `.venv`，並安裝 pybind11 及 C++ 編譯所需的工具。

接著修改 `grade.cpp` 中的 TODO，完成三個 Task 的 C++ 程式與 Python 綁定設定。完成後，使用 g++ 編譯產生 `.so` 模組，讓 Python 能透過 `import gradecpp` 載入 C++ 功能。

之後修改 `lab.py`，透過 Python 呼叫 `gradecpp.add_bonus()`、`gradecpp.average_scores()`，以及建立 `gradecpp.GradeBook()` 物件進行測試。

最後執行：

```bash
python lab.py
```

得到以下結果：

```text

[PASS] Task 2 / list 與 vector
[PASS] Task 3 / C++ Class

結果：3/3 關通過
```

## 三、遇到的問題與解決方法

這次遇到的主要問題是，第一次成功編譯 C++ 程式後，執行 `python lab.py` 卻顯示三個 Task 全部失敗，而且實際結果都是 `None`。

一開始我不確定是 C++ 程式、pybind11 綁定，還是編譯過程出了問題。後來透過 AI Tutor 協助檢查 `grade.cpp`，確認 C++ 的計算函式和綁定設定都已完成，再進一步檢查 `lab.py`，才發現 Python 部分的 TODO 還沒有修改，測試程式仍然使用 `None` 當作預設值。

修正後，Python 才真正呼叫到 C++ 函式，三個 Task 也全部通過。

這次讓我學到，**編譯成功不代表整個程式功能都正確**。除了確認 C++ 能編譯，也需要檢查 Python 是否有正確呼叫函式，並透過測試確認實際輸出。

## 四、AI Tutor 的協助

這次主要使用 AI Tutor 協助理解 pybind11 的語法、完成 TODO，以及排除測試失敗的問題。

AI Tutor 將實驗拆成三個 Task，逐步解釋 `std::min()`、`std::vector`、`push_back()`、`m.def()` 和 `py::class_` 等語法，讓我能理解每個部分的用途，而不是直接一次修改整份程式。

在第一次測試得到 0/3 時，AI Tutor 也根據錯誤訊息中的 `None`，引導我檢查 Python 程式，最後找出問題並成功修正。

## 五、本週心得與反思

這週我覺得比較有趣的是，原本以為 Python 和 C++ 是兩種不同的程式語言，程式應該要分開執行，但透過 pybind11，竟然可以直接在 Python 裡建立 C++ 物件並呼叫它的方法。

我也發現 pybind11 並不是把 C++ 程式轉換成 Python，而是透過編譯產生的模組，讓兩種語言可以互相配合。這樣就能利用 Python 比較方便的操作方式，同時保留 C++ 在效能與程式架構上的優勢。

另外，這次從 0/3 FAIL 修正到 3/3 PASS 的過程，也讓我更了解除錯時應該先根據錯誤訊息判斷問題發生在哪一層，而不是一看到失敗就重新安裝或重寫整個程式。
