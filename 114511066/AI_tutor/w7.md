# W07 AI Tutor 學習紀錄

## 一、本週學習內容

這週主要進行 MOOS-IvP Lab06 的 Tug of War 實驗，透過修改不同 Behavior 的 Priority Weight（PWT），觀察 IvP Helm 如何在多個行為之間進行決策。

實驗中使用兩個主要 Behavior：

- `BHV_Waypoint`：設定船隻朝東方的 Waypoint 前進，目標速度為 2.0。
- `BHV_ConstantHeading`：設定船隻朝正北方（Heading = 0°）航行。

我透過調整這兩個 Behavior 的 PWT，觀察船隻的 Heading、Speed 和航行軌跡，了解不同權重如何影響最終的航行方向。

## 二、實驗過程與結果

這次實驗共測試四種 Case：

| Case | PWT_EAST | PWT_NORTH | 觀察結果 |
|---|---|---|---|
| 1 | 100 | 100 | 船隻朝東北方向航行，Heading 約 32.1° |
| 2 | 100 | 30 | 船隻更偏向東方，Heading 約 70° |
| 3 | 30 | 100 | 船隻停止移動，Speed = 0 |
| 4 | 100 | 0 | 船隻幾乎朝正東方航行，Heading 約 84° |

從 Case 1、2、4 可以發現，當東向 Behavior 的權重相對提高時，船隻的航向會逐漸接近正東方（90°）。這讓我理解 PWT 並不是直接指定船隻的方向，而是決定不同 Behavior 在 IvP Helm 最佳化過程中的影響程度。

另外，我也學到，如果將兩個 PWT 同時乘上相同的正數，在其他條件不變的情況下，理論上不會改變加權 Objective Function 的最佳解，因為兩個 Behavior 的相對權重沒有改變。

## 三、遇到的問題與解決方法

這週最特別的問題是 Case 3 的船完全不動。

一開始我以為是模擬沒有成功啟動，但後來透過 AI Tutor 的協助，查看 `pHelmIvP` 的資訊，發現兩個 Behavior 都處於 Active 狀態，而且 Helm 的決策為：

```text
speed  = 0
course = 0
```

這代表系統有正常運作，只是最後選擇了零速度。

進一步檢查 `meta_tug.bhv` 後，我發現 `BHV_ConstantHeading` 主要提供航向偏好，而 `BHV_Waypoint` 同時考慮航向與速度。在 Case 3 的權重配置下，兩個 Objective Function 的加權結果使 Helm 選擇停止移動。

為了解決這個問題，我保留原本的 `PWT_EAST=30` 和 `PWT_NORTH=100`，另外新增一個 `BHV_ConstantSpeed`：

```text
Behavior = BHV_ConstantSpeed
{
    name       = go_speed
    pwt        = 100
    condition  = DEPLOY = true

    speed      = 2.0
    duration   = no-time-limit
    peakwidth  = 0
    basewidth  = 0.2
}
```

重新執行 Case 3 後，`pHelmIvP` 顯示三個 Behavior 都正常啟動，最後的決策變成：

```text
speed  = 2
course = 0
```

船隻成功以 2.0 m/s 朝正北方航行，證明可以在不降低原本 PWT 的情況下，透過增加新的 Behavior 改善航行結果。

## 四、AI Tutor 的協助

這次我主要使用 AI Tutor 協助分析模擬結果與排除問題。

AI Tutor 先協助我比較四個 Case 的差異，說明 Priority Weight 與航向之間的關係。當 Case 3 的船沒有移動時，AI Tutor 引導我查看 `pHelmIvP` 的 Helm Decision，以及使用 Terminal 檢查 `meta_tug.bhv` 中的 Behavior 設定。

在確認問題後，AI Tutor 建議我新增 `BHV_ConstantSpeed`，並說明各個參數的用途。我依照建議修改設定、重新執行模擬，最後透過 `pHelmIvP` 確認三個 Behavior 都正常運作。

## 五、本週心得與反思

這週讓我印象最深刻的是，原本以為提高某個方向的 PWT，船就一定會朝那個方向移動，但 Case 3 讓我發現事情沒有這麼簡單。即使 Helm 選擇了正確的 Desired Heading，也可能因為 Speed 被選為 0，導致船完全不動。

我覺得這個實驗最有收穫的地方，是學會不能只看船的航行軌跡判斷程式是否正常，而是要進一步觀察 Helm Decision 和各個 Behavior 的狀態。透過這次修改，我也更理解 MOOS-IvP 是如何將不同的行為偏好整合成最終控制決策，而不是單純按照權重選擇其中一個 Behavior。
