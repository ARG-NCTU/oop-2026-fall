# Lab06：MOOS-IvP 行為拔河（Tug of War）

一艘船上同時有兩個行為，想去的方向不一樣，觀察 `pHelmIvP` 如何依照權重（`pwt`）決定航向與航速。

## 兩個行為

| 行為 | 類型 | 想做什麼 | 在乎什麼 |
|---|---|---|---|
| `go_east` | `BHV_Waypoint` | 前往東邊的航點 `(3000, 0)` | 航向和航速都在乎 |
| `go_north` | `BHV_ConstantHeading` | 船頭朝正北（0°） | 只在乎航向，不管航速 |

Helm 對每一種「航向（0～359°）＋ 航速（0～4 m/s）」的組合計算：

```text
總分 = pwt_east × go_east 的分數 + pwt_north × go_north 的分數
```

然後選總分最高的組合。

## 執行方式

```bash
cd ~/moos-ivp/ivp/missions/exp1_tugofwar
./launch.sh --case=1
```

地圖出現後按 **DEPLOY**。換別的 case 前，先在終端機按 `Ctrl + C` 關掉。

## 問題與回答

### 1. 每個 Case 觀察到什麼？

| Case | 東 : 北 | 航向 | 航速 | 船怎麼開 |
|---|---|---|---|---|
| 1 | 100 : 100 | 約 38° | 約 3.3 | 往東北開，偏北 |
| 2 | 100 : 30 | 約 68° | 約 2.1 | 往東北開，偏東較多 |
| 3 | 30 : 100 | 0° | **0** | 停住不動 |
| 4 | 100 : 0 | 約 84° | 約 2.0 | 直直開向目標 |

哪一邊的權重越大，船就越往那一邊偏。Case 4 北的權重是 0，等於只剩往東的行為；目標在出發點 `(0, -300)` 的東北偏東，所以是 84° 而不是 90°。

### 2. 兩個權重等比例縮放，結果會變嗎？

**不會。** 例如 100 : 100 改成 50 : 50，或 100 : 30 改成 10 : 3，航向與航速都一樣。兩個權重同時乘上同一個數，每一種組合的總分也都乘上同一個數，最高分的組合不變。真正影響結果的是權重的**比例**。

### 3. Case 3 的船為什麼不動？

北的權重 100 比東的 30 大，所以 Helm 選擇朝北。

但 `go_north` 只管航向、不管航速。`go_east`（`ipf_type = roc`）的分數由兩部分組成：

```text
go_east 的分數 = 0.8 × 接近分 + 0.2 × 繞路分
```

繞路分的意思是：沒有對準目標還開得越快，扣分越多。船頭朝北時與目標方向差了約 84°，往北開幾乎沒有接近目標，開越快只是越偏離，所以對 `go_east` 而言**速度 0 的分數最高**。

唯一在乎航速的行為希望停下來，Helm 就選了速度 0。船沒有速度，舵也沒有作用，所以船頭一直停在一開始的方向。

### 4. 不刪減權重，如何讓 Case 3 的船動起來？

在 `meta_tug.bhv` 新增一個只在乎航速、不管航向的行為 `BHV_ConstantSpeed`，並用 `#ifdef CASE 3` 只加在 Case 3：

```text
#ifdef CASE 3
Behavior = BHV_ConstantSpeed
{
  name      = keep_speed
  pwt       = 50
  condition = DEPLOY = true

      speed = 2.0
   duration = no-time-limit
}
#endif
```

| 設定 | 說明 |
|---|---|
| `pwt = 50` | 新加的行為也要有權重；原本兩個權重都沒有修改 |
| `speed = 2.0` | 希望維持 2 m/s |
| `duration = no-time-limit` | 一直有效，不會啟動後立刻結束 |

**結果：** 船維持朝北（0°），速度變成 2.0 m/s，開始前進。

**原因：** `keep_speed` 最喜歡速度 2，權重 50 比 `go_east` 的 30 大。從速度 0 改成速度 2，`go_east` 因為繞路少掉的分數，比不上 `keep_speed` 增加的分數，所以 Helm 改選速度 2。`keep_speed` 對每個航向給的分數都一樣，不會跟 `go_north` 搶方向，所以航向仍然是北。
