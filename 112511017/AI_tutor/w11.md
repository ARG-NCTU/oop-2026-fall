### 1. Today's Challenge

Title: Find a safe route around closed stations.

Implement `shortest_safe_route(graph, start, goal, closed)`. `graph` maps every station to its ordered list of outgoing neighbors. Return a minimum-edge route from start to goal that visits no closed station, or `None` if no route exists. If several routes are equally short, use the one discovered first by FIFO BFS following the listed neighbor order.

A valid start equal to the goal returns `[start]`. A closed start or goal always returns `None`. Preserve the graph and the closure list.

Constraints: 1–10,000 vertices, at most 50,000 listed edges, and station names of 1–20 ASCII characters. All neighbors and endpoints are graph keys; every closed name is a graph key. Cycles, self-loops, and duplicate edges are allowed. The closure list has at most 10,000 entries. Edges are unweighted and directed.

For `graph = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}`:

| Start | Goal | Closed | Output |
| --- | --- | --- | --- |
| `"A"` | `"D"` | `["B"]` | `["A", "C", "D"]` |
| `"D"` | `"A"` | `[]` | `None` |
| `"A"` | `"A"` | `[]` | `["A"]` |

Lecture concept transferred: adjacency lists and BFS. The added constraint is excluding closed stations. Parent links avoid copying an entire path for every queued candidate.

### 5. Verification

#### Final implementation

```python
def shortest_safe_route(graph, start, goal, closed):
    """Find a minimum-edge directed route that avoids every closed node."""
    blocked = dict.fromkeys(closed)
    if start in blocked or goal in blocked:
        return None

    parents = {start: None}
    queue = [start]
    head = 0
    while head < len(queue):
        node = queue[head]
        head += 1
        if node == goal:
            path = []
            while node is not None:
                path.append(node)
                node = parents[node]
            path.reverse()
            return path

        for neighbor in graph[node]:
            if neighbor not in blocked and neighbor not in parents:
                parents[neighbor] = node
                queue.append(neighbor)
    return None
```

### 6. One-Minute Reflection

Why it works: FIFO processing explores routes by edge count. Every discovered station is open and has a parent on a valid route. The first discovery of a station has minimum distance; later discoveries cannot improve it. Parent links therefore reconstruct a minimum-edge route. If the queue empties, every reachable open station has been processed.

Complexity: expected O(V + E + B) time and O(V + B) extra space, including path reconstruction, for V vertices, E edges, and B closure entries. Dictionary operations are expected constant time under the bounded-name constraint. Each vertex is queued at most once.

What I understand better: the data structure and visitation rule are part of the complexity argument. A FIFO queue alone does not prevent redundant work if the same vertex can be enqueued repeatedly.
