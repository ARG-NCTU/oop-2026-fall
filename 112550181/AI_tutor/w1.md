## ② My Misconception

### Before: I thought…

Assigning one list variable to another, such as `b = a`, copied the value of the list. I also did not clearly distinguish between modifying an existing list and assigning a variable to a newly created list.

### Now: I understand…

`b = a` makes both variables refer to the same list object rather than copying it. Mutating the list through either alias affects the same object. However, an expression such as `a = a + [3]` creates a new list and makes `a` refer to it, while other aliases still refer to the original list. I also understand that `a[:]` performs only a shallow copy, so mutable objects inside a nested list can still be shared.
