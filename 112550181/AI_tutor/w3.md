## ② My Misconception

### Before: I thought…

I initially thought that `assert` was an appropriate general-purpose way to handle invalid user input. I also considered returning a special value such as `-1` to be a cleaner and more controllable way to signal an error.

### Now: I understand…

Assertions and exceptions serve different purposes. An assertion is mainly used to verify assumptions that the developer expects to always hold, such as preconditions, postconditions, or invariants. If an assertion fails, it usually indicates a bug or an invalid internal program state.

Exceptions are more appropriate for abnormal situations that may legitimately occur during execution, such as invalid user input, because the program can catch the exception and execute an alternative recovery path.

I also understand that special error return values can make callers more complicated because every caller must remember to check for them. Raising an exception separates normal return values from error-handling control flow more clearly.
