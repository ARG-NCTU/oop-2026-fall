## ② My Misconception

### Before: I thought…

I understood `self` as the first parameter of an instance method, but I loosely thought that it could simply be omitted.

### Now: I understand…

`self` represents the particular instance on which a method operates. It must be represented as the first parameter when defining an instance method. However, when calling a method through an instance, such as `a.distance(b)`, Python automatically supplies `a` as the `self` argument. This is why `a.distance(b)` is conceptually equivalent to `Coordinate.distance(a, b)`.

I also understand more clearly that a class defines a new object type, while each call to the class constructor creates a separate instance, even when two instances contain identical attribute values.
