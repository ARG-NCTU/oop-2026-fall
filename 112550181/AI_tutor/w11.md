## ② My Misconception

### Before: I thought…

I correctly recognized that the first path found by depth-first search (DFS) is not necessarily the shortest path. However, I thought that this limitation might disappear if the graph were a directed acyclic graph (DAG).

### Now: I understand…

Acyclicity prevents directed cycles, but it does not force DFS to explore paths in increasing order of length. Even in a DAG, DFS could first find a path with three edges while a different path to the same destination uses only one edge. DFS must continue exploring appropriate alternatives to guarantee the shortest unweighted path. Breadth-first search (BFS), by contrast, explores paths in increasing order of edge count, so the first destination it finds is reached by a shortest unweighted path.

I also understand that the fewest edges is not necessarily the lowest total weight. Ordinary BFS does not automatically solve the weighted shortest-path problem. For sparse graphs, adjacency lists generally use less space than adjacency matrices, although the matrix can be more direct for checking whether a particular edge exists.
