## ② My Misconception

### Before: I thought…

I understood that class variables are shared, but I initially focused on the fact that they are accessed using the class name, such as `Rabbit.tag`, rather than `self`.

### Now: I understand…

The important distinction is where the variable is defined. A class variable is defined in the class scope, outside `__init__`, and is shared by all instances. Instance variables such as `self.rid`, `self.name`, or `self.age` belong to individual objects and can have different values for each instance.

I also understand that inheritance does not mean every parent method is always executed automatically. If a child class overrides a method, Python uses the closest implementation in the inheritance hierarchy. Similarly, if a subclass defines its own `__init__`, the parent `__init__` must be called explicitly if its initialization behavior is still needed.
