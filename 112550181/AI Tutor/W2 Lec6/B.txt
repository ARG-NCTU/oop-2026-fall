2. My Initial Approach — Before AI Help

My approach:

I recognized the problem as a variation of the Fibonacci recurrence. The number of ways to reach step `n` can normally be expressed as the sum of the ways to reach steps `n-1` and `n-2`. If a step is blocked, the number of ways to reach that step should be zero. I planned to store the number of ways to reach previously computed steps in a dictionary.

3. AI Tutor Help

The most useful hint/question from AI was:

The memoization dictionary should belong to one execution of the problem instead of being shared globally between calls with different blocked-step configurations.

It helped me realize that:

A cached result is only valid for the conditions under which it was computed. If the blocked steps change, previously stored path counts may no longer be correct. The memo should therefore be created separately for each top-level call.

Did you change your approach or code after interacting with AI?

What did you change, and why?

I moved the memoization dictionary inside `count_paths()` and used a recursive helper function so that each call receives a fresh cache. I also handled negative steps and blocked steps as base cases before performing recursive calls.

5. Verification

My final program:

```python
def count_paths(n, blocked):
    memo = {0: 1}

    def helper(k):
        if k < 0:
            return 0
        if k in blocked:
            return 0
        if k in memo:
            return memo[k]

        memo[k] = helper(k - 1) + helper(k - 2)
        return memo[k]

    return helper(n)
```

6. One-Minute Reflection

What idea from the OCW lecture did you transfer to this new problem?

I transferred the recursive idea of reducing a problem to smaller versions of the same problem. To find the number of ways to reach step `n`, I use the results for steps `n-1` and `n-2`. I also used a dictionary to memoize intermediate results so repeated recursive subproblems do not need to be recomputed.

One thing I understand better now:

I understand that a recursive solution needs both a valid base case and recursive calls that actually move toward that base case. I also understand more clearly how dictionaries can be used as caches for intermediate recursive results.
