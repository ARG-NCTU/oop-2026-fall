② My Misconception

Before: I thought…

I thought types such as `int` and `float` could be considered mutable because a variable containing them can be assigned a different value after it is created.

Now: I understand…

Reassigning a variable is different from mutating an object. For example, `x = 3` followed by `x = 4` makes `x` refer to a different integer object; the integer `3` itself was never modified. Mutable objects such as lists and dictionaries can instead have the contents of the existing object changed. This is why immutable objects can be used as dictionary keys while lists cannot.
