## ② My Misconception

### Before: I thought…

I did not have a major misconception that required revising an answer, but I mainly thought of greedy algorithms as simply choosing the best-looking option at each step.

### Now: I understand…

An optimization problem is defined by an objective function to maximize or minimize and a set of constraints that valid solutions must satisfy.

For the 0/1 knapsack problem, greedy choices are not guaranteed to produce a globally optimal solution because items cannot be divided. Choosing an item with the best value-to-weight ratio can leave unused capacity that prevents a better combination of items from being selected.

In contrast, the fractional knapsack problem allows items to be divided, so choosing items in decreasing order of value-to-weight ratio can produce an optimal solution.

I also understand that brute force is guaranteed to find the optimal 0/1 knapsack solution because it checks every possible subset, but there are `2^n` subsets, so its running time grows exponentially.
