## Part B: LeetCode-style lecture code transfer

### Lecture concept

The slides use **#217 Contains Duplicate** to demonstrate how a Python `set` records values already seen in an array.

### Challenge title

**First Repeated Value**

### Problem statement

Given a list of integers `nums`, return the first value that appears for a second time while scanning the list from left to right. If no value repeats, return `None`.

**Input:** A list of integers, `nums`.  
**Output:** An integer (the first repeated value) or `None`.  
**Constraints:** `1 <= len(nums) <= 10000`; values are between `-10000` and `10000`.

**Examples:**

- `nums = [4, 2, 7, 2, 4]` → `2`
- `nums = [1, 3, 5]` → `None`
- `nums = [9, 9]` → `9`

### Initial approach before help

I would check each number against the numbers already encountered. A nested-loop solution could work, but it would repeat comparisons.

### AI tutor hints

The lecture's `Contains Duplicate` example suggests storing previously encountered values in a `set` and checking membership before adding each value.

### Revised solution (Python)

```python
def firstRepeated(nums):
    seen = set()
    for num in nums:
        if num in seen:
            return num
        seen.add(num)
    return None
```

### Verification and edge cases

| Input | Expected | Reason |
|---|---:|---|
| `[4, 2, 7, 2, 4]` | `2` | `2` is repeated first |
| `[1, 3, 5]` | `None` | No duplicates |
| `[9, 9]` | `9` | Two adjacent copies |
| `[-1, 0, -1]` | `-1` | A negative value can also repeat |

**Edge case:** Returning `None` for no duplicate avoids confusing that outcome with a repeated `-1`.

### Transfer from lecture and understanding gained

I reused the `seen` set from Contains Duplicate, but changed the return value: instead of `True` or `False`, the function returns the first value repeated. Set membership checks usually take average O(1) time, making the whole scan average O(n) time with O(n) extra space.

### Remaining uncertainty

I want more practice determining when a set is sufficient and when a dictionary is needed to keep extra information, such as indices in Two Sum.
