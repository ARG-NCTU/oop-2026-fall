## Part B: LeetCode-style Lecture Code Transfer

### 1. Today's Challenge

**Core concept from the OCW lecture:**

Independent applications communicating through shared, published information and high-level decisions controlling vehicle navigation.

**Proposed AI-generated coding challenge title:**

Square-Patrol Command Planner

**Problem statement:**

Write a C++ function that generates four waypoints for an axis-aligned square patrol, starting from the bottom-left corner. Write another function that selects a speed for the named control modes `MUCHSLO` and `MUCHFST`. This is a small C++ model of two tasks from the MOOS-IvP demonstration; it is **not** a working MOOS application.

**Input/output specification:**

- Input: lower-left `x`, `y`, positive square side length `side`, and a speed-mode string.
- Output: four ordered 2D points along the square, plus the selected speed in m/s.
- `MUCHSLO` gives `1.0` m/s; `MUCHFST` gives `4.0` m/s.
- Invalid side lengths or unknown modes throw `std::invalid_argument`.

**Constraints:**

- Use C++ `std::vector`, `std::pair`, and functions.
- Require `side > 0`.
- This challenge illustrates the lecture concepts but does not substitute for running `pAntler` or modifying the MOOS mission files.

**Example:**

```text
Input: x=0, y=0, side=10, mode="MUCHSLO"
Waypoints: (0,0), (10,0), (10,10), (0,10)
Speed: 1.0 m/s
```
