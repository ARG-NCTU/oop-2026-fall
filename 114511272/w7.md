## Part B: LeetCode-style Lecture Code Transfer

### 1. Today's Challenge

**Core concept:** Combine behavior utilities using priority weights and choose the candidate with the highest total score.

**Challenge title:** Best Heading and Speed Candidate

**Problem statement:** Given a list of possible boat-control decisions, each with a heading, a speed, an eastward-navigation utility, and a northward-heading utility, find the candidate with the highest weighted score:

`score = east_weight * east_utility + north_weight * north_utility`

If scores tie, select the candidate with the lower speed. If speeds also tie, select the smaller heading. These tie-break rules are for this programming exercise, not a claim about the real IvP Helm implementation.

**Input:** Two integer weights and a list of candidates `(heading, speed, east_utility, north_utility)`.  
**Output:** The chosen `(heading, speed)`.  
**Constraints:** At least one candidate; nonnegative integer weights and utilities; nonnegative speeds.

**Example 1:**

```text
east_weight = 100, north_weight = 100
candidates = [(0, 0, 0, 100), (45, 2, 80, 80), (90, 2, 100, 0)]
output = (45, 2)
# Scores: 10000, 16000, 10000
```

**Example 2:**

```text
east_weight = 30, north_weight = 100
candidates = [(0, 0, 0, 100), (45, 2, 80, 50), (90, 2, 100, 0)]
output = (0, 0)
# Scores: 10000, 7400, 3000
```

**Example 3 (tie):**

```text
east_weight = 1, north_weight = 1
candidates = [(90, 2, 50, 50), (0, 0, 70, 30)]
output = (0, 0)
# Same score; prefer lower speed
```

### 4. My Revision and Final Program

I used a single loop to evaluate the candidates. I track the best candidate and update it when a higher score appears. When there is a tie, I apply the given speed and heading rules.

```python
def best_candidate(east_weight, north_weight, candidates):
    best = None
    best_score = None

    for heading, speed, east_util, north_util in candidates:
        score = east_weight * east_util + north_weight * north_util

        if (best is None or score > best_score or
            (score == best_score and (speed, heading) < (best[1], best[0]))):
            best = (heading, speed)
            best_score = score

    return best
```

**Complexity:** `O(n)` time for `n` candidates and `O(1)` additional space.
