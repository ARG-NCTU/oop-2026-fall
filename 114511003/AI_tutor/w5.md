#### Question 1

Statement:

```python
class Animal:

```

因為 `Cat` 沒有定義自己的 `__init__`，所以 `Cat(3)` 會產生錯誤，無法建立 `c`。

My answer: False.

Reason: `Cat` inherits Animal's initialization method. Since `Cat` does not define its own `__init__`, it uses `Animal.__init__`, so the object is created successfully and `c.age == 3`.

#### Question 2

```python

```

即使 `Cat` 定義了自己的 `__init__`，Python 仍會自動執行 `Animal.__init__`，所以會印出 `3`。

My first answer: True.

AI hint: `Cat.__init__` 只有設定 `self.name`，沒有設定 `self.age`，也沒有呼叫 `Animal.__init__`。參數 `age` 是否會自動變成實例屬性？

Corrected answer: False.

Explanation after revision: When a subclass defines its own `__init__`, the parent initializer does not run automatically. This example needs an explicit call to `super().__init__(age)`. Otherwise, `self.age` is not created, and `print(c.age)` raises an `AttributeError`.

### 5. My final program

```python
class LibraryItem:
    def __init__(self, title):
        self._title = None
        self.set_title(title)

    def get_title(self):
        return self._title

    def set_title(self, title):
        if not isinstance(title, str):
            raise TypeError("書名必須是字串 (str)")
        if title == "":
            raise ValueError("書名不可為空字串")
        self._title = title

    def loan_days(self):
        return 14

    def __str__(self):
        return f"item:{self._title}"

class ReferenceBook(LibraryItem):
    def loan_days(self):
        return 0

    def __str__(self):
        return f"reference:{self._title}"
```

### 7. Why my solution works

`LibraryItem` 統一管理書名。初始化呼叫 `set_title()`，讓建立物件與後續修改使用相同的驗證規則。驗證全部通過後才指定 `self._title`，所以修改失敗時原書名不會被覆蓋。

`ReferenceBook` 沒有自訂 `__init__`，因此沿用父類別初始化，也繼承 getter 與 setter。它只覆寫 `loan_days()` 與 `__str__()`，讓相同的方法呼叫依物件類別提供不同結果。每個實例各自保存 `_title`，修改其中一個不影響另一個。

### 8. Time and space complexity

令 `n` 為書名長度，依一般 Python 字串操作成本計算：

- 修正後 `set_title()` 與初始化時間、額外空間為 `O(1)`。型別檢查與比較空字串不需掃描整個書名，指定屬性保存字串參照，不複製內容。
- `get_title()` 與 `loan_days()` 時間、額外空間為 `O(1)`。
- `__str__()` 建立包含書名的新字串，時間與輸出空間為 `O(n)`。
- 實例保存固定數量的參照，本身為 `O(1)` 空間；若計入書名內容則為 `O(n)`。

初版的 `strip()` 最壞需要 `O(n)` 時間與 `O(n)` 暫存空間；移除後也避免了不必要的字串處理。
