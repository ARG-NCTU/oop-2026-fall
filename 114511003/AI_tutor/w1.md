#### Question 1

Statement:

```python
a = [1, 2]
b = a
b.append(3)
```

The value of `a` becomes `[1, 2, 3]`.

Answer: True

Reason: `a` and `b` refer to the same List object, so changing the List through `b` also changes what `a` refers to. This is aliasing.

#### Question 4

Statement:

```python
L1 = [1, 2, 3, 4]
L2 = [1, 2]

for value in L1:
    if value in L2:
        L1.remove(value)
```

After the loop, `L1` is `[3, 4]`.

Answer: False

Reason: Removing an element while iterating changes the positions of the remaining elements. The loop can skip an element. In this example, `L1` becomes `[2, 3, 4]`.

#### Question 5

```python

clone[0].append(5)
```

After the code runs, `original` is still `[[1, 2], [3, 4]]`.

Answer: False

Reason: `original[:]` only creates a shallow copy. The outer Lists are different, but the inner Lists are still shared. Therefore, changing `clone[0]` also changes `original[0]`.

### 1. Today's challenge

AI-generated coding challenge title: Remove duplicates while preserving first appearance order.

#### Problem statement

Given a List of integers, remove duplicate values while keeping the first occurrence of each value. Do not use a `set`.

#### Input and output

- Input: a List of integers.
- Output: a new List containing each value once, in its original order.

#### Constraints

- The input may be empty.
- The input may contain negative numbers and repeated values.
- Do not use a `set`.
- The original input List should not be modified.

#### Examples

```text
Input:  [3, 1, 3, 2, 1, 2]
Output: [3, 1, 2]

Input:  []
Output: []

Input:  [5, 5, 5]
Output: [5]
```

### 2. My initial approach - before AI help

My first idea was to copy the input List and use a counter while iterating. I then realized that one counter could not separately track the number of times that different values appeared.

I changed the approach to create an `output` List. For each input value, I compare it with every value already in `output`. If it is not present, I append it. This keeps the first occurrence and skips later duplicates.

The Lecture 5 concepts I applied are List traversal, membership checking, and avoiding direct modification of the List being iterated over.

### 3. AI Tutor help

I asked the AI Tutor for help.

The most useful hint was to compare each current input value with the entire `output` List, rather than comparing it with only `output[0]` or using one counter for all values. The AI also reminded me to handle an empty input before accessing `input[0]`.

It helped me realize that the algorithm needs to remember all values that have already been kept, not just the most recent value.

### 4. My revision

Yes, I changed my approach.

I changed from using one counter to checking whether each value already existed in `output`. This works for values that appear in different positions and preserves their first appearance order.

My final program is:

```python
def remove_duplicates(Input):
    output = []

    if len(Input) > 0:
        output.append(Input[0])

        for i in Input:
            a = 1

            for j in output:
                if i == j:
                    a = 0

            if a != 0:
                output.append(i)

        return output
    else:
        return Input
```
