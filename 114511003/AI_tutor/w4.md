#### Question 2

Statement:

```python
class Coordinate:
    def __init__(self, x, y):
        self.x = x
        self.y = y

point = Coordinate(3, 4)
```

建立 `point` 時，呼叫者必須自己把 `self` 寫成第一個參數。

My first answer: True

Corrected answer: False

Reason: Python automatically passes the new instance as the first argument to `__init__`. The values `3` and `4` are passed to `x` and `y`. The caller does not write `self`.

This call:

```python
point = Coordinate(3, 4)
```

can be understood as:

```python
Coordinate.__init__(point, 3, 4)
```

#### Question 3

Statement:

```python
def __init__(self, x, y):
    self.x = x
```

左邊的 `self.x` 是目前 instance 的 attribute，右邊的 `x` 是 method 收到的參數。

My answer: True

Reason: The left side, `self.x`, is the `x` attribute stored in the current instance. The right side, `x`, is the parameter received by the method. Therefore, `self.x = x` stores the parameter value in the instance.

For example, when `self` represents `point`, `self.x = x` stores the value of `x` in `point.x`. Writing only `x = x` would not create an instance attribute.

### 5. My final program

```python
class Coordinate:
    def __init__(self, x, y):
        if not isinstance(x, (int, float)):
            raise TypeError("x must be an int or float")

        if not isinstance(y, (int, float)):
            raise TypeError("y must be an int or float")

        self.x = x
        self.y = y

    def distance(self, other):
        if not isinstance(other, Coordinate):
            raise TypeError("other must be a Coordinate")

        dx = self.x - other.x
        dy = self.y - other.y
        return (dx ** 2 + dy ** 2) ** 0.5

    def __str__(self):
        return f"<{self.x},{self.y}>"
```

### 7. Why my solution works

建立 `Coordinate` instance 時，`__init__` 先檢查 `x` 和 `y` 的型別，再把資料存到 `self.x` 和 `self.y`。`distance()` 使用目前的 `self` 和另一個 `other` 計算兩點距離。`__str__()` 把 instance 的資料轉成固定格式的字串。

這個設計讓資料和操作資料的方法放在同一個 class 中，也讓不同的座標 instance 可以使用相同的 method。

### 8. Time and space complexity

`distance()` 只做固定數量的減法、乘法和開根號運算，因此：

- 時間複雜度：`O(1)`。
- 額外空間複雜度：`O(1)`。

`__str__()` 也只處理兩個座標值，所以時間和額外空間複雜度都是 `O(1)`。建立一個 instance 只保存 `x` 和 `y`，需要 `O(1)` 空間。
