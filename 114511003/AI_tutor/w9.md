### 1. Today's challenge

Core concept from today's OCW lecture: 使用排序規則安排檢查順序，再逐一判斷是否加入結果。

AI-generated coding challenge title: Maximum number of workshops.

#### Problem statement

一天有多場工作坊，你只能同時參加一場。每場都有開始與結束時間，參加時必須完整出席。請回傳最多可以參加幾場工作坊。

工作坊的時間區間為 `[start, end)`，因此前一場結束時間等於下一場開始時間時，可以接著參加。

#### Input and output

- Input: `workshops`，每個元素為整數 tuple `(start, end)`。
- Output: 最多能參加的場數，型別為 `int`。
- Function signature: `def max_workshops(workshops):`

#### Constraints

- `0 <= len(workshops) <= 10000`。
- 每場滿足 `0 <= start < end <= 1000000`。
- 輸入可能未排序、可能為空，也可能有相同時間的不同場次。
- 不修改原始輸入 list。
- 目標為最多場數，每場的計分相同。
- 以 `O(n log n)` 時間或更好為目標，並說明額外空間。

#### Examples

```text
Input: [(1, 3), (2, 5), (3, 4), (4, 6)]
Output: 3
Explanation: 可以依序參加 (1, 3)、(3, 4)、(4, 6)。

Input: [(1, 10), (2, 3), (3, 4), (4, 5)]
Output: 3
Explanation: 可以參加三場較短的工作坊。

Input: []
Output: 0
```

### 5. Verification

My final program:

以下是我依 AI 提示修正後提供的程式，`get_end_time` 回傳 `workshop[1]` 作為排序依據。

```python
# 取得工作坊的結束時間，用來當作排序的依據
def get_end_time(workshop):
    return workshop[1]

def max_workshops(workshops):
    # 依照「結束時間」由小到大排序，並建立新串列（不修改原資料）
    sorted_workshops = sorted(workshops, key=get_end_time)

    count = 0      # 紀錄參加的場數
    last_end = 0   # 紀錄上一場工作坊的結束時間

    for start, end in sorted_workshops:
        # 如果這場的開始時間晚於或等於上一場的結束時間，就可以參加
        if start >= last_end:
            count += 1
            last_end = end  # 更新目前的結束時間

    return count
```

Test results:

AI verified the corrected program on 2026-11-27. It passed 5 example and edge cases, 1,024 comparisons against brute force, and a chain of 10,000 workshops.

Time complexity: `O(n log n)` for sorting, followed by an `O(n)` scan.

Space complexity: `O(n)` extra space for the sorted list and sorting workspace.
