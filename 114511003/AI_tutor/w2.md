#### Question 1

Statement:

```python
def f(n):
    return f(n - 1)
```

This is a correct recursive solution because the function calls itself.

My answer: False

Reason: Calling itself only makes a function recursive. A correct recursive
solution also needs a base case and a recursive step that moves toward that
base case. This function has neither a reachable base case nor a stopping
condition, so it eventually raises `RecursionError`.

#### Question 2

Statement:

If a recursive function has a base case, it is guaranteed to terminate.

My first answer: False

AI hint: Consider a function whose base case is `n == 0`, but whose recursive
case calls itself with `n + 1` and starts with `n = 3`.

Correct answer: False

Reason: The recursive call must make progress toward the base case. Merely
writing a base case is not enough if the input moves farther away from it or
never changes.

#### Question 3

Statement:

Each recursive call to a function has its own local environment.

My answer: True

Reason: Every function call creates its own call frame and local variables.
For example, when `factorial(4)` calls `factorial(3)`, the two calls have
different values of `n`. After the deeper call returns, the earlier call
continues with its own saved environment.

#### Question 4

Statement:

Dictionary keys must be unique and hashable, while dictionary values may be
duplicated.

My answer: True

Reason: A dictionary can have only one value for each key. Assigning the same
key again replaces its previous value. Keys must be hashable, such as strings,
integers, booleans, or tuples. Values can repeat and can be mutable objects
such as lists or other dictionaries.

The part I needed help with: I was not sure which type could not be used as a
key. I learned that `list` is mutable and cannot be used as a dictionary key.

#### Question 5

Statement:

Memoization makes recursive Fibonacci faster by storing results that have
already been calculated in a dictionary.

My answer: True

Reason: The direct recursive Fibonacci function calculates the same smaller
values many times. Memoization first checks whether the answer is already in
the dictionary. Each input value is then calculated at most once, changing the
time complexity from exponential to linear for one complete calculation.

### 5. My final program

```python
def nested_score_total(scores):
    if not isinstance(scores, dict):
        raise TypeError("scores must be a dictionary")

    keys = list(scores.keys())

    def visit(index):
        if index == len(keys):
            return 0

        value = scores[keys[index]]

        if isinstance(value, int):
            current = value
        elif isinstance(value, dict):
            current = nested_score_total(value)
        else:
            raise TypeError("each value must be an integer or dictionary")

        return current + visit(index + 1)

    return visit(0)
```

### 7. Why my solution works

空 dictionary 沒有任何分數，所以 base case 回傳 `0`。對非空 dictionary，
函式逐一處理每個 value。遇到整數時直接加入；遇到 dictionary 時，將它交給
同一個函式處理。每次遞迴都進入更小的 nested dictionary，因此最後會抵達
空 dictionary 或最內層的整數。

### 8. Time and space complexity

令 `n` 為整個巢狀 dictionary 中的 value 數量。

- 時間複雜度：`O(n)`，每個 value 只處理一次。
- 額外空間：`O(d)`，其中 `d` 是巢狀深度，代表遞迴 call stack 的最大深度。
- 若把 `list(scores.keys())` 產生的 keys list 也算入空間，還要加上目前各層
  keys list 的空間。
