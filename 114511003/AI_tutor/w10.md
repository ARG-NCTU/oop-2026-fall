#### Question 4

#### Question 5

Statement: If a recursive optimization algorithm has optimal substructure, adding memoization always makes it efficient, even when no two recursive calls solve the same subproblem.

My first answer: False.

My reasoning: "it depend on how many calls share the same subproblem".

AI hint, revision, and feedback: No hint or revision was needed. Memoization saves repeated computation when calls share a state. Overall running time depends on the number of distinct states and the work per state; even overlapping subproblems do not guarantee a small state space.

### 5. Verification

My final program:

```python
def min_energy(heights):
    # 輸入為空串列
    if not heights:
        raise ValueError("heights cannot be empty")

    n = len(heights)
    memo = {}  # 用字典記錄「從索引 i 跳到終點的最少能量」

    def solve(i):
        # 終止條件：已經站在最後一個平台上
        if i == n - 1:
            return 0

        if i in memo:
            return memo[i]

        # 選擇 1：跳 1 格
        cost_one = abs(heights[i + 1] - heights[i]) + solve(i + 1)

        # 選擇 2：跳 2 格（需確認 i + 2 沒有超過最後一個平台）
        if i + 2 < n:
            cost_two = abs(heights[i + 2] - heights[i]) + solve(i + 2)
            best = min(cost_one, cost_two)
        else:
            best = cost_one

        # 把最佳結果存入 memo 後再回傳
        memo[i] = best
        return best

    # 從索引 0 開始出發
    return solve(0)
```
