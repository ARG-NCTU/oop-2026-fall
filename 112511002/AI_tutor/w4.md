### 1. Today's Challenge

- Core concept from today's OCW lecture：class、instance、self、狀態與方法介面。
- AI-generated coding challenge title：設計可重複使用的座位預約器。

#### Problem statement

設計 `SeatPool(capacity)`。初始剩餘座位等於 capacity。`reserve(k)`：若座位足夠，扣除 k 並回傳 True；否則回傳 False 且保持狀態。`release(k)`：若釋出後不超過 capacity，增加 k 並回傳 True；否則回傳 False 且保持狀態。`available()` 回傳目前剩餘座位。不同物件必須獨立。

#### Input / Output

- 輸入：建構子接收 capacity；各方法接收正整數 k。以一串方法呼叫檢查物件行為。
- 輸出：reserve/release 回傳 bool；available 回傳 int。
- 限制：`0 <= capacity <= 1000`；`1 <= k <= 1000`；最多 1000 次操作。題目保證輸入型別合法，不要求處理例外。

#### Examples

| 輸入／操作 | 預期結果 |
| --- | --- |
| `容量 3；依序 reserve(2)、available()、reserve(2)、available()` | `True、1、False、1` |
| `容量 2；依序 reserve(2)、release(1)、available()` | `True、True、1` |
| `容量 1；依序 release(1)、available()` | `False、1` |
