### 1. Today's Challenge

- Core concept from today's OCW lecture：遞迴分解、基本情況、dictionary 查詢與 tuple/list 資料。
- AI-generated coding challenge title：統計資料夾樹的檔案數。

#### Problem statement

實作 `count_files(catalog, root)`。`catalog` 用資料夾名稱作 key，value 是 `(本層檔案數, 子資料夾名稱list)`。請用遞迴回傳 root 及所有子資料夾中的檔案總數，不可修改 catalog。

#### Input / Output

- 輸入：`catalog` 為 dictionary；`root` 是存在於 catalog 的資料夾名稱。
- 輸出：一個非負整數，表示整棵子樹的檔案數。
- 限制：最多 100 個資料夾；深度最多 50；本層檔案數介於 0 到 1000。root 的子樹無循環，每個非 root 資料夾只有一個父資料夾，所有引用名稱都存在。不需處理不合法結構。

#### Examples

| 輸入／操作 | 預期結果 |
| --- | --- |
| `count_files({'main': (2, ['a', 'b']), 'a': (1, []), 'b': (3, [])}, 'main')` | `6` |
| `count_files({'main': (0, ['a']), 'a': (2, ['b']), 'b': (4, [])}, 'main')` | `6` |
| `count_files({'main': (0, [])}, 'main')` | `0` |
