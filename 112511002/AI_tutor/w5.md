### 1. Today's Challenge

- Core concept from today's OCW lecture：繼承、方法覆寫、共同介面與 instance state。
- AI-generated coding challenge title：用共同介面計算不同票種總價。

#### Problem statement

設計 `Ticket` 與兩個子類別 `RegularTicket`、`StudentTicket`。兩種票都接收非負整數 base_price，並提供 `price()`。一般票回傳 base_price；學生票回傳 base_price 的一半並向下取整。再實作 `total_price(tickets)`，透過各物件的 price() 計算總價；不得用票種名稱或 type/isinstance 分支決定價格。Ticket 負責保存基本價格與定義共同介面。

#### Input / Output

- 輸入：各票的 base_price，以及由兩種票物件組成的 tickets list。
- 輸出：price() 與 total_price() 都回傳非負 int。
- 限制：`0 <= base_price <= 10000`；`0 <= len(tickets) <= 1000`；不要求處理非法型別。只需本週範圍的普通類別與繼承，不需抽象類別套件。

#### Examples

| 輸入／操作 | 預期結果 |
| --- | --- |
| `total_price([RegularTicket(100), StudentTicket(100)])` | `150` |
| `total_price([StudentTicket(99), RegularTicket(1)])` | `50` |
| `total_price([])` | `0` |
