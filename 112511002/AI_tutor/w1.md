- AI-generated coding challenge title：建立互不干擾的活動分組。

#### Problem statement

實作 `make_groups(names, group_size)`，依原本順序把名字分成若干組。每組最多 `group_size` 人，最後一組可以較少。回傳 `(groups, group_count)`。不可修改 `names`；不同組必須是不同的 list，之後在某一組加入名字，不應改變其他組或原始輸入。

#### Input / Output

- 輸入：`names` 是名字組成的 list；`group_size` 是正整數。
- 輸出：tuple：第一項是 list of lists；第二項是組數。
- 限制：`0 <= len(names) <= 1000`；`1 <= group_size <= 1000`；名字可以重複。

#### Examples

| 輸入／操作 | 預期結果 |
| --- | --- |
| `make_groups(['Ana', 'Bo', 'Cy', 'De', 'El'], 2)` | `([['Ana', 'Bo'], ['Cy', 'De'], ['El']], 3)` |
| `make_groups(['Ana', 'Ana'], 1)` | `([['Ana'], ['Ana']], 2)` |
| `make_groups([], 3)` | `([], 0)` |
