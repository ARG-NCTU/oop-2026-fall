### 1. Today's Challenge

- Core concept from today's OCW lecture：逐一走訪、提前停止、操作計數、最佳與最差情況。
- AI-generated coding challenge title：回報第一次超標與實際比較次數。

#### Problem statement

實作 `first_over_limit(readings, limit)`，依序檢查整數讀值。找到第一個嚴格大於 limit 的讀值後立即停止，回傳 `(index, comparisons)`；找不到則回傳 `(-1, comparisons)`。index 使用 0 起算。comparisons 只計算實際執行 `讀值 > limit` 的次數，不包含迴圈控制等其他操作。不可先掃完整份資料再回報較少的比較次數。

#### Input / Output

- 輸入：整數 list readings 與整數 limit。
- 輸出：tuple：第一次超標的位置（或 -1）與實際數值比較次數。
- 限制：`0 <= len(readings) <= 10000`；讀值與 limit 介於 -1000000 到 1000000。不修改輸入，使用逐一檢查。

#### Examples

| 輸入／操作 | 預期結果 |
| --- | --- |
| `first_over_limit([4, 9, 2, 10], 8)` | `(1, 2)` |
| `first_over_limit([1, 2, 3], 3)` | `(-1, 3)` |
| `first_over_limit([], 5)` | `(-1, 0)` |
