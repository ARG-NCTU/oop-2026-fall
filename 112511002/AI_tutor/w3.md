### 1. Today's Challenge

- Core concept from today's OCW lecture：規格、輸入檢查、ValueError、邊界測試。
- AI-generated coding challenge title：驗證分數並計算平均。

#### Problem statement

實作 `checked_average(scores)`。輸入是整數分數 list。若 list 為空，或任何分數不在 0～100（含端點），必須拋出 `ValueError`。其餘情況回傳平均值。不可改動輸入，也不能把錯誤默默改成 0。

#### Input / Output

- 輸入：`scores` 是整數 list；題目保證元素為 int 且不是 bool，無需處理其他型別。
- 輸出：合法時回傳 float 平均值；不合法時拋出 ValueError。
- 限制：`0 <= len(scores) <= 1000`；輸入整數介於 -1000 到 1000。有效分數為 0～100。

#### Examples

| 輸入／操作 | 預期結果 |
| --- | --- |
| `checked_average([60, 80, 100])` | `80.0` |
| `checked_average([0, 100])` | `50.0` |
| `checked_average([])` | `拋出 ValueError` |
