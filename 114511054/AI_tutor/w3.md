### 4. My Revision

- Approach / code changes: 演算法未修改；僅整理縮排及新增驗證程式。
- Final source: [w3.py](w3.py)

```python
def import_scores(raw_scores):
    valid = []
    rejected = []
    for i, text in enumerate(raw_scores):
        try:
            score = int(text)
        except ValueError:
            rejected.append((i, text, "not_integer"))
            continue
        if 0 <= score <= 100:
            valid.append(score)
        else:
            rejected.append((i, text, "out_of_range"))
    return {"valid": valid, "rejected": rejected}
```
