## Part B: LeetCode-style Lecture Code Transfer

### 1. Today's Challenge

**Title: Independent Sensor Batches**

實作 `clean_batches(batches, minimum)`。輸入為巢狀 list，每個內層 list 是一批感測數值；回傳各批保留大於等於 `minimum` 的數值後的新巢狀 list，保留原順序與空批次。

Constraints:
- 數值與門檻皆為整數；最多 100 批，每批最多 100 個元素。
- 不得修改輸入的外層或內層 list。
- 回傳值中的內層 list 不得與輸入共用同一個 list 物件。
- 使用本週的 list 走訪、條件判斷與複製概念。

Examples:
1. `clean_batches([[1, 5, 3], [8, 2]], 3)` → `[[5, 3], [8]]`
2. `clean_batches([[], [-3, -1, 0]], -1)` → `[[], [-1, 0]]`
3. `clean_batches([], 10)` → `[]`

Additional verification: 修改輸出中的某批次後，再檢查原輸入是否保持不變。

### 2. My Initial Approach — Before AI Help

- My proposed algorithm (student): 外層與每個批次都重新建立 list。外層 comprehension 走訪每批，內層 comprehension 篩選 `x >= minimum`，保留順序與空批次。
- Concept from the lecture (student): 區分淺拷貝與獨立的巢狀結構。數字不可變，因此可以共用元素，不需要對整數使用 `copy.deepcopy`。

### 3. AI Tutor Help

- Did I receive hints: 本題的思路、程式與隔離測試由學生先提供，AI 未代寫解題方案；此前 Part A 曾討論 alias、淺拷貝與深拷貝。
- Tutor assistance after submission: AI 檢視思路、整理貼文中的程式排版，加入題目三個範例與全部被過濾的測試，並實際執行測試。
- Clarification: 對本題兩層 list、整數元素的輸入，重新建立外層與內層即可保證所需獨立性；此寫法不等同對任意更深可變巢狀物件進行完整 deepcopy。

### 4. My Revision

- Did I change my algorithm after AI review: 無；原本的巢狀 list comprehension 保留不變。
- What changed and why: 僅由 AI 整理排版並整合可執行驗證，未修改演算法。
- My final program and executable checks: [w1.py](w1.py)

```python
def clean_batches(batches, minimum):
    return [[x for x in batch if x >= minimum] for batch in batches]
```
