## Part B: Concept Transfer — Weighted Heading Choice

### 1. Today's Challenge

實作 choose_heading(candidates, waypoint_pwt, heading_pwt)。這是有限候選的 Python 概念練習，不連接 MOOSDB、不重現完整 IvP 求解器，也不宣稱預測 Tug of War 實際軌跡。

candidates 是 tuple 的 list，每筆為 (heading, waypoint_utility, heading_utility)。每個候選的分數定義為 waypoint_pwt * waypoint_utility + heading_pwt * heading_utility。

回傳最高分候選的新 dictionary：{'heading': 航向, 'score': 分數}。最高分相同時，選數值較小的航向；空 list 回傳 None。不得修改輸入。

Constraints:

- 最多 360 個候選；航向互不重複，為 0–359 的整數。
- 兩種效用保證為 0–100 的整數。
- 兩個 PWT 保證為 0–1000 的整數，可以為 0。
- 兩個 PWT 都為 0 時仍按同分規則選擇，不另拋出例外。
- 輸入保證符合規格，不要求額外型別驗證。
- 不使用外部套件。
- 同分時選最小航向是本題自訂規則，不代表真實 IvP Solver 的同分選擇規則。

Examples:

1. choose_heading([(0, 20, 100), (90, 100, 10)], 2, 1) → {'heading': 90, 'score': 210}
2. choose_heading([(90, 100, 0), (0, 0, 100)], 1, 1) → {'heading': 0, 'score': 100}
3. choose_heading([], 1, 1) → None

Additional verification: 只有一個候選；其中一個權重為 0；兩個權重皆為 0；反轉同分候選的輸入順序；輸入前後相同。

### 4. My Revision

- Approach / code changes: 解法與測試邏輯未修改，只以 UTF-8 LF 保存。
- Program and original verification: [choose_heading.py](choose_heading.py)

```python

def choose_heading(candidates, waypoint_pwt, heading_pwt):
    best_heading = None
    best_score = None
    for heading, waypoint_utility, heading_utility in candidates:
        score = waypoint_pwt * waypoint_utility + heading_pwt * heading_utility
        if (best_score is None
                or score > best_score
                or (score == best_score and heading < best_heading)):
            best_heading, best_score = heading, score
    if best_score is None:
        return None
    return {"heading": best_heading, "score": best_score}

```

### 6. Correctness, Complexity and Concept Transfer

使用者提供的正確性說明：處理完前 k 筆後，目前最佳就是前 k 筆中「分數最高，同分時航向最小」的候選。第一筆先成為最佳，之後只在更高分或同分更小航向時更新，最後結果符合整體排序且與輸入順序無關。

使用者提供的複雜度：n 為候選數，逐筆計算並比較一次，時間 O(n)；只保存幾個變數與回傳 dict，額外空間 O(1)，沒有排序或複製 list。此處依題目固定範圍的整數運算視為常數。

使用者提供的概念對應：兩個效用值對應兩個行為對同一候選的目標函數值；兩個 PWT 對應權重；加權相加再取最大值對應整體目標求解。本題只考慮離散航向，實際 Helm 可有航向、速度等多維決策。權重為 0 的目標在本題加權分數中沒有貢獻；同乘正數可驗證最佳航向不變、分數同比放大。

同分取最小航向是本題自訂規則，不宣稱真實 IvP Solver 有相同 tie-breaking，也未執行實際 MOOS 任務。
