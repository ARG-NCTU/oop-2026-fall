#### Question 1 — Recursion termination

- Statement: 每個遞迴函式只要寫了 base case，就保證一定會終止，不需要考慮參數是否朝 base case 接近。
- Initial answer and reasoning: **錯。** 只有 base case 不夠，每次遞迴呼叫的參數還必須越來越接近 base case。反例：`f(n)` 在 `n == 0` 時回傳，否則呼叫 `f(n - 1)`，但如果傳入 `f(-1)` 就永遠到不了 0，最後會出現 `RecursionError`。
- AI hint / counterexample: 無；初答正確。
- Revised answer and reasoning: 未修正。
- Concept confirmed: 必須有可達的終止條件，並考慮輸入範圍與每次呼叫如何推進至終止條件。

#### Question 2 — Hashable dictionary keys

- Statement: Dictionary 的 key 必須可雜湊（hashable）；一般 list 不能直接作為 key。
- Initial answer and reasoning: **對。** dict 用 key 的 hash 值來找資料，所以 key 必須可雜湊。list 是可變的，沒有 hash 值，拿來當 key 會出現 `TypeError: unhashable type: 'list'`。需要的話可以先轉成 `tuple`。
- AI hint / counterexample: 初答後補充：轉成 tuple 仍須確認所有元素可雜湊；學生在 Challenge the AI 中已自行提出含 list 的 tuple 作為反例。可變性與可雜湊性並非對所有 Python 物件都等同。
- Revised answer and reasoning: 是非判斷未修正；tuple 的限制由學生自己的挑戰題補充。
- Concept confirmed: list 不可雜湊；tuple 是否可雜湊取決於它的元素是否都可雜湊。

#### Question 3 — Missing dictionary keys

- AI hint / counterexample: 無；對本題一般 dict 的情境，初答正確。

#### Question 4 — Return and unreachable statements

Statement: 以下程式呼叫 `f(3)`，會印出 `3`、`2`、`1`。

```python

```

- Initial answer and reasoning: **錯。** 什麼都不會印。`print(n)` 寫在 `return` 後面，永遠不會執行到。`f(3)` 只會一路遞迴到 `f(0)`，最後回傳 `0`。
- AI hint / counterexample: 無；初答正確。
- Revised answer and reasoning: 未修正。
- Concept confirmed: `return f(n - 1)` 先求得遞迴呼叫的回傳值，再結束當前呼叫；後面的 `print` 不會執行。

#### Question 5 — Dictionary aliasing

Statement: 執行後，透過 `a` 也能看到 `"wire"` 的值變成 `2`。

- Revised answer and reasoning: 未修正。

### 1. Today's Challenge

**Title: Nested Supply Inventory**

實作 `count_supplies(tree)`。輸入是巢狀 list，元素為物品名稱字串或另一個 list。遞迴走訪所有字串，回傳每個名稱出現次數的 dictionary。

Constraints:
- 不存在循環參照；巢狀深度最多 20，總元素數最多 1000。
- 名稱非空、區分大小寫；不得修改輸入。
- 使用遞迴與 dictionary 累計次數；不使用尚未學過的外部套件。

Examples:
1. `count_supplies(['wire', ['bolt', 'wire'], []])` → `{'wire': 2, 'bolt': 1}`
2. `count_supplies([])` → `{}`
3. `count_supplies([['nut'], ['Nut', ['nut']]])` → `{'nut': 2, 'Nut': 1}`

Additional verification: 同一名稱只在深層出現時，與同一名稱散在不同分支時的統計。

### 2. My Initial Approach — Before AI Help

學生提供的解題思路：

- **字串**：在 dict 裡把這個名稱的計數加 1。
- **內層 list**：對它遞迴呼叫，交給下一層處理。
- **停止**：遇到字串或空 list 就不再往下呼叫。每次遞迴都進入更小的子 list，又沒有循環參照，所以一定會結束。
- **跨層累計**：所有層共用同一個 `counts` dict，不管名稱出現在哪一層、哪個分支，都加到同一筆。
- Concept from the lecture I intend to apply: 遞迴的 base case 和縮小問題規模；dictionary 計數；共用同一個可變物件。

```python
def count_supplies(tree):
    counts = {}

    def walk(node):
        for item in node:
            if isinstance(item, str):
                counts[item] = counts.get(item, 0) + 1
            else:
                walk(item)

    walk(tree)
    return counts
```
