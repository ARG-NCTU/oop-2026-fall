**AI-generated coding challenge title:**

Inventory Updates with Rejected Requests

### Problem Statement

Implement `process_inventory(initial_stock, requests)` to process inventory changes in order:

- Positive integers represent incoming stock, negative integers represent outgoing stock, and zero is a valid request.
- Reject any request that cannot be converted into an integer.
- Reject an entire request if it would make the stock negative.
- A rejected request must leave the stock unchanged. Continue processing subsequent requests.
- If the initial stock is negative, raise `ValueError`.

### Input / Output Specification

| Item | Specification |
|---|---|
| `initial_stock` | An integer representing the starting stock |
| `requests` | A list of request strings in processing order |
| Return value | `[final_stock, rejected_indices]` |
| `rejected_indices` | The zero-based indices of rejected requests, in their original order |

### Constraints

- `-10⁶ ≤ initial_stock ≤ 10⁶`
- `0 ≤ len(requests) ≤ 1000`
- Each string contains between `0` and `20` characters.
- Requests that can be converted into integers have values between `-10⁶` and `10⁶`.
- Do not modify `requests`.
- Use exception handling for conversion failures and an `assert` statement to check that stock remains nonnegative.

### Examples

| Input | Expected Result |
|---|---|
| `5, ["-3", "4", "-7", "2"]` | `[8, [2]]` |
| `0, ["abc", "3", "-3", "0"]` | `[0, [0]]` |
| `-1, []` | Raise `ValueError` |

**Program code:**

```python
def process_inventory(initial_stock, requests):
    if initial_stock < 0:
        raise ValueError("Initial stock cannot be negative")

    stock = initial_stock
    rejected_indices = []

    for index in range(len(requests)):
        try:
            change = int(requests[index])
        except ValueError:
            rejected_indices.append(index)
        else:
            if stock + change < 0:
                rejected_indices.append(index)
            else:
                stock += change

        assert stock >= 0, "Stock cannot be negative"

    return [stock, rejected_indices]
```

**One edge case I tested:**

Input: `initial_stock = 5, requests = []`  
Expected output: `[5, []]`  
Actual output: `[5, []]`

**Why the solution works:**

The initial stock is checked first. Each request updates the stock only if it can be converted into an integer and would not make the stock negative. Otherwise, only its index is recorded. Therefore, the final stock reflects all accepted changes, and rejected requests are recorded in order.

**Time complexity:**

`O(n)`, where `n` is the number of requests. Each request is processed once, and each string has a maximum length of 20 characters.
