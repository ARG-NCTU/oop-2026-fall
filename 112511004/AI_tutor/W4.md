**What did you change, and why?**

我改成先確認誰先開始。假設 A 先開始，我提出的公式是：

```python
min(B.end, A.end) - min(A.end, B.start)
```

如果 B 先開始，就交換兩場會議在計算中的角色。我曾想到複製 B，但經討論後知道只需用變數指向原物件，不必複製或修改它們。

| 項目 | 原本的想法 | 修正後 |
|---|---|---|
| 開始順序 | 先比較 A 結束與 B 開始。 | 先確認誰先開始，再套用公式。 |
| B 先開始的處理 | 複製 B 到新物件運算。 | 讓 B 扮演較早開始的會議，不必複製。 |
| 無重疊案例 | 對 `(120,180)` 與 `(60,90)` 回答 30。 | 30 是空檔，重疊應為 0。 |
| 時間複雜度 | `O(n)` | 運算步驟固定，因此是 `O(1)`。 |

**My final program:**

```python
class Meeting:
    def __init__(self, start, end):
        self.start = start
        self.end = end

    def overlap(self, other):
        if self.start <= other.start:
            earlier = self
            later = other
        else:
            earlier = other
            later = self

        return (
            min(earlier.end, later.end)
            - min(earlier.end, later.start)
        )
```

**Why my solution works:**

有重疊時，兩場會議從較晚的開始時間起同時進行，到較早的結束時間為止，所以兩者相減就是重疊長度。

若先開始的會議在另一場開始前或剛開始時就結束，公式中的兩個 `min` 會取得相同的結束時間，相減得到 `0`，表示沒有重疊。

`earlier` 與 `later` 只是指向原本物件，程式沒有重新指定物件的時間屬性，因此不會修改原資料。

**Time complexity:** `O(1)`，只有固定次數的比較與減法。  
**Extra space complexity:** `O(1)`，只使用固定數量的區域變數。
