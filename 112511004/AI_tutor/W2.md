What did you change, and why?

I changed my proposed approach from maintaining candidate and removed-event lists to using a dictionary of occurrence counts. After counting, the program scans the original list to find the first event with a count of 1.

I also corrected my time-complexity answer from O(2), then O(n²), to O(n). Two sequential scans require at most approximately 2n steps, assuming dictionary operations take constant time on average.

⸻⸻⸻

5. Verification

My final program:

def first_unique_event(events):
    counts = {}

    for event in events:
        if event in counts:
            counts[event] += 1
        else:
            counts[event] = 1

    for event in events:
        if counts[event] == 1:
            return event

    return -1
