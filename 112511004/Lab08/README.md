## 1. Two Sum

### 題目說明

給定整數陣列 `nums` 與目標值 `target`，找出兩個相加等於 `target` 的元素，回傳它們的索引。

題目保證恰有一組解，同一個元素不能重複使用，回傳索引的順序不限。

### 範例

```text
輸入：nums = [2, 7, 11, 15], target = 9
輸出：[0, 1]

說明：
nums[0] + nums[1] = 2 + 7 = 9
因此回傳索引 [0, 1]。
```

### 函式介面

```c
int* twoSum(int* nums, int numsSize, int target, int* returnSize);
```

### 解題思路

本程式使用兩層迴圈，逐一檢查不同位置的兩個元素是否能相加得到 `target`。

1. 先將 `*returnSize` 設為 `0`，表示目前尚未找到答案。
2. 外層迴圈選定第一個元素 `nums[i]`，計算還需要的數值：

   ```c
   int needed = target - nums[i];
   ```

3. 內層迴圈從 `i + 1` 開始，尋找是否有 `nums[j] == needed`。從下一個位置開始，可以避免重複使用同一個元素，也不會重複檢查相同的配對。
4. 找到答案後，使用 `malloc()` 配置可存放兩個整數的陣列。
5. 將索引 `i`、`j` 存入結果陣列，並將 `*returnSize` 設為 `2`，最後回傳結果。
6. 若記憶體配置失敗或沒有找到答案，回傳 `NULL`，此時 `*returnSize` 維持為 `0`。

### 記憶體管理

結果陣列使用動態記憶體配置：

```c
int* result = malloc(2 * sizeof(int));
```

### 複雜度

- 時間複雜度：`O(n²)`，最壞情況需要檢查所有元素配對。
- 額外空間複雜度：`O(1)`，結果陣列固定只存放兩個索引。

### 注意事項

- 回傳的是索引，不是兩個數值。
- 相同數值可以來自不同位置，例如 `[3, 3]`、`target = 6` 的答案為 `[0, 1]`。
- 內層迴圈從 `i + 1` 開始，確保兩個索引不同。
- 使用 `malloc()` 後，先檢查是否回傳 `NULL`，再寫入資料。

## 20. Valid Parentheses

### 題目說明

給定只包含 `(`、`)`、`[`、`]`、`{`、`}` 的字串 `s`，判斷括號是否有效。

有效括號需要符合以下條件：

- 左括號必須由相同種類的右括號閉合。
- 括號必須依照正確順序閉合。
- 每個右括號都必須有對應的左括號。

### 範例

| 輸入 | 預期輸出 | 說明 |
|---|---|---|
| `"()"` | `true` | 一組正確配對。 |
| `"()[]{}"` | `true` | 多組括號依序配對。 |
| `"([])"` | `true` | 巢狀括號依正確順序閉合。 |
| `"(]"` | `false` | 括號種類不符。 |
| `"([)]"` | `false` | 括號閉合順序錯誤。 |

### 函式介面

```c
bool isValid(char* s);
```

輸入為括號字串，回傳值表示括號是否完整且正確配對。

### 解題思路

本程式使用動態配置的字元陣列模擬堆疊，利用「後進先出」的特性，優先檢查最近出現的左括號。

1. 使用 `strlen()` 取得字串長度 `n`。
2. 若字串長度為 `0`，直接回傳 `true`；若長度為奇數，括號不可能完整配對，直接回傳 `false`。
3. 使用 `malloc()` 配置容量為 `n` 的堆疊，並以 `top` 記錄目前存放的左括號數量。若配置失敗，回傳 `false`。
4. 由左至右讀取字串：
   - 遇到左括號時，存入 `stack[top]`，再將 `top` 加一。
   - 遇到右括號時，先檢查堆疊是否為空。
   - 若堆疊為空，代表沒有左括號可以配對，釋放記憶體後回傳 `false`。
   - 若堆疊不為空，取出 `stack[top - 1]`，檢查括號種類是否相符。
   - 若種類不符，釋放記憶體後回傳 `false`；若配對成功，將 `top` 減一，移除該左括號。
5. 字串走訪結束後，先釋放堆疊記憶體，再檢查 `top` 是否為 `0`。只有所有左括號都完成配對，才回傳 `true`。

### 堆疊操作範例

以 `s = "([])"` 為例：

| 讀取字元 | 操作 | 堆疊內容 | `top` |
|---|---|---|---:|
| `(` | 放入左括號 | `(` | 1 |
| `[` | 放入左括號 | `([` | 2 |
| `]` | 與頂端的 `[` 配對並移除 | `(` | 1 |
| `)` | 與頂端的 `(` 配對並移除 | 空 | 0 |

最後 `top == 0`，代表所有括號皆已配對，回傳 `true`。

### 記憶體管理

堆疊透過以下方式配置：

```c
char* stack = malloc(n * sizeof(char));
```

### 複雜度

- 時間複雜度：`O(n)`，計算字串長度與檢查括號皆為線性操作。
- 額外空間複雜度：`O(n)`，堆疊配置的容量與字串長度相同。

### 注意事項

- 不能只比較左右括號的數量，也要檢查種類與順序。
- 讀取 `stack[top - 1]` 前，必須先確認 `top` 不為 `0`。
- 走訪結束後若仍有左括號留在堆疊中，應回傳 `false`。
- 程式依題目限制，假設輸入只包含六種括號字元。


## 121. Best Time to Buy and Sell Stock

### 題目說明

給定陣列 `prices`，其中 `prices[i]` 表示第 `i` 天的股價。

最多進行一次買入與一次賣出，且必須先買入，再於之後的某一天賣出，求能得到的最大獲利。若無法獲利，回傳 `0`。

### 範例

```text
輸入：prices = [7, 1, 5, 3, 6, 4]
輸出：5

說明：
第 2 天以價格 1 買入，第 5 天以價格 6 賣出。
最大獲利為 6 - 1 = 5。
```

```text
輸入：prices = [7, 6, 4, 3, 1]
輸出：0

說明：
股價持續下降，無法透過一次先買後賣取得正獲利。
```

### 參考解題思路

可以透過單次走訪，維護「目前最低買入價」與「目前最大獲利」。

1. 將第一天的股價設為目前最低買入價，最大獲利設為 `0`。
2. 從第二天開始，計算今天賣出相對於先前最低買入價的獲利。
3. 若獲利較高，更新最大獲利。
4. 若今天的價格更低，更新最低買入價。
5. 走訪結束後，回傳最大獲利。

每次計算都使用先前出現的買入價格，因此符合先買後賣的限制。

### 參考解法複雜度

- 時間複雜度：`O(n)`。
- 額外空間複雜度：`O(1)`。

### 注意事項

- 不能直接使用整個陣列的最大值減最小值，因為最高價可能出現在最低價之前。
- 本題只允許一次買入與一次賣出。
- 若無法獲利，應回傳 `0`。

## C 語言實作重點

### 透過指標回報結果長度

Two Sum 除了回傳結果陣列，也透過 `returnSize` 回報陣列長度：

```c
*returnSize = 2;
```

這個操作會修改呼叫端提供的變數，讓呼叫端知道結果陣列包含幾個元素。

### 確認動態記憶體的釋放責任

| 配置的記憶體 | 釋放責任 |
|---|---|
| Two Sum 的結果陣列 | 由呼叫端在使用完畢後釋放。 |
| Valid Parentheses 的堆疊 | 由 `isValid()` 在回傳前釋放。 |

使用 `malloc()` 後應檢查是否配置成功，並確認各個回傳路徑都有適當處理記憶體。
