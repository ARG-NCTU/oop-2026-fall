## 程式解析

### 1. 計算初始圓面積

```python
pi = 3.14159
radius = 2.2
area = pi * (radius ** 2)
print(area)
```

圓面積公式為 `π × r²`，其中 `**` 表示次方。賦值時，Python 先算出右側運算式的結果，再將左側名稱 `area` 綁定到這個值。

### 2. 更新半徑，觀察既有面積

```python
radius = radius + 1
print(area)
```

Python 先讀取原本的 `radius`，加上 `1`，再把結果指定回 `radius`，所以半徑變為 `3.2`。但 `area` 仍保存先前的計算結果，不會自動追蹤半徑的變化。

### 3. 重新計算面積

```python
area = pi * (radius ** 2)
print(area)
```

這次運算使用更新後的半徑，`area` 才會取得新的值。

| 執行階段 | `radius` | `area`，約取小數四位 |
|---|---:|---:|
| 第一次計算後 | 2.2 | 15.2053 |
| 只更新半徑後 | 3.2 | 15.2053 |
| 第二次計算後 | 3.2 | 32.1699 |

### 4. 註解與自動補全

原始檔案另包含兩段編輯器練習：

- **註解**：以 `#` 開頭的內容不會作為 Python 敘述執行。可在編輯器切換多行註解，觀察程式執行範圍的變化。
- **自動補全**：以刻意較長的變數名稱練習補全功能。原始檔將該變數設為 `0`；「改成 `1` 並印出」仍是註解中的練習提示，現有程式沒有執行這兩個步驟。

原註解使用 Spyder 的 `Ctrl+1` 與 Tab 操作提示；快捷鍵依編輯器設定而定，不影響 Python 程式本身的執行。

### 基本型別與轉換

| 型別／操作 | 範例 | 說明 |
|---|---|---|
| `int` | `5` | 整數 |
| `float` | `3.0` | 浮點數，以有限精度表示數值 |
| `bool` | `True`、`False` | 布林值 |
| `NoneType` | `None` | 表示沒有值等情況的特殊物件型別 |
| `type()` | `type(3.0)` | 取得物件的型別，這裡為 `float` |
| `float()` | `float(3)` | 結果為 `3.0` |
| `int()` | `int(3.9)` | 結果為 `3`，向零截斷，不是四捨五入 |

### 算術運算

| 運算子 | 用途 | 範例結果 |
|---|---|---|
| `+` | 加法 | `3 + 2` → `5` |
| `-` | 減法 | `3 - 2` → `1` |
| `*` | 乘法 | `3 * 2` → `6` |
| `/` | 除法 | `3 / 2` → `1.5` |
| `%` | 取餘數 | `3 % 2` → `1` |
| `**` | 次方 | `3 ** 2` → `9` |

可使用括號明確表達運算順序。乘、除、取餘數屬於相同優先層級，加、減也屬於相同層級；同層的這些運算子由左至右計算。
