#### 2. My Initial Approach — Before AI Help

**Before asking AI for hints, briefly describe how you planned to solve the problem.**

**My approach:** 這題用 dictionary 查表，用空間換時間，避免暴力法兩層迴圈的 O(n²)。

1. 由左往右依序遍歷 j（從 index 0 到 n-1）。
2. 對於當前的數字 nums[j]，要找前面出現過、數值為 complement = target - nums[j] 的 index i。
3. 用一個字典 `seen` 記錄每個看過的數字對應的 index，字典查詢平均是 O(1)。
4. 為什麼能滿足題目的限制：
   - 「j 最小的那一組」：因為是從小到大掃描 j，第一個找到符合的配對時，當下的 j 就是全域最小的合法 j。
   - 「j 相同時取 i 最小」：字典只記錄每個數值第一次出現的 index（已存在就不覆蓋），所以取出來的 i 保證最小。
   - 找到第一組合法配對就立刻回傳 `(seen[complement], j)`；整條跑完都沒找到就回傳 `None`。

時間複雜度：只有一層迴圈，跑 n 步，每次字典的查詢和寫入平均都是 O(1)，所以平均時間複雜度是 O(n)，額外空間是 O(n)。
