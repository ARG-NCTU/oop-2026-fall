### Algorithm, Correctness, and Complexity

**Algorithm:** For position p, return 0 if p is blocked or exceeds N. Return 1 if p equals N and is not blocked. Otherwise return routes(p+1) + routes(p+2), saving each computed value in a dictionary.

**Why it works:** Every valid route from a nonterminal position begins with exactly one of the two allowed moves. These two groups are disjoint, so their counts can be added. Invalid landings contribute 0 and reaching the valid finish contributes one completed route. Caching preserves those results.

**Time and space complexity:** O(N) time and O(N) auxiliary space for the cache and recursion stack, assuming average O(1) dictionary operations and unit-cost arithmetic. Each reachable position is expanded at most once. The given N limit also keeps recursion depth small.
