### Question 3
Statement: The result of 7 / 2 is the same type and value as 7 // 2.

Reference answer: **False**. In Python 3, these are 3.5 and 3 respectively.

Suggested hint: Compare ordinary division with floor division.

### Question 4
Statement: For positive capacity K, quotient and remainder can describe full boxes and leftovers.

Reference answer: **True**. N = (N // K)*K + N % K, with a remainder from 0 to K-1.

### Algorithm, Correctness, and Complexity

**Algorithm:** Calculate full = N // K and leftover = N % K. Since 0 <= leftover < K, (leftover + K - 1) // K is 0 when leftover is 0 and 1 otherwise. Add that value to full to obtain the required boxes. Unused slots equal required * K - N.

**Why it works:** The quotient-remainder identity gives N = full*K + leftover. The extra-box expression is exactly the indicator for a nonzero leftover, so required is the smallest sufficient box count. The difference between total capacity and item count is precisely the unused space.

**Time and space complexity:** O(1) time and O(1) auxiliary space under the usual fixed-size arithmetic model. Python arbitrary-precision arithmetic has a cost dependent on integer size.
