## Part B: LeetCode-style Lecture Code Transfer

### 1. Today's Challenge

Core concept: Divide and conquer, Merge Sort, and counting comparisons between two sorted halves.  
Challenge title: Count Out-of-Order Pairs

Problem: Given a list of integers, count the pairs of indices `(i, j)` for which `i < j` and `nums[i] > nums[j]`. Return the count without modifying the input list.

Example: `[2, 4, 1, 3, 5]` has three inversions: `(2,1)`, `(4,1)`, and `(4,3)`; output `3`.

### 2. My Initial Approach — Before AI Help

The most direct idea is to compare every element with the elements after it. This is correct, but takes O(n²) time. I wanted to connect the problem to Merge Sort to improve efficiency.

### 3. AI Tutor Help

Did I use AI help? Yes — to review the problem design, solution, and test cases.

Most useful idea: When the current element of the right half is smaller than the current element of the sorted left half, it is also smaller than all remaining elements in that left half.

What I learned: I can count several inversions at once during a merge instead of checking every pair individually.

### 4. My Revision

I used a helper function returning both a sorted list and its inversion count. Each recursive call counts inversions within its half, and the merge step counts inversions crossing the two halves. This keeps the logic separate and avoids changing the original input.
