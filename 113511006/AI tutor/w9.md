## Part B: LeetCode-style Lecture Code Transfer

### 1. Today's Challenge

Core concept: Greedy activity selection and sorting by finishing time.  
Challenge title: Schedule Talks With Cleanup Time

Problem: A classroom has talks represented by `(start, finish)` times. After each talk, the room needs a fixed nonnegative cleanup period. Select the maximum possible number of talks and return their original indices in attendance order.

Example: `talks = [(1,3),(3,5),(5,7)]`, `cleanup = 1` gives `[0,2]`.

### 2. My Initial Approach — Before AI Help

I would sort the talks by finishing time, then select a talk if its start time is no earlier than the end of the previous chosen talk plus cleanup time.

### 3. AI Tutor Help

Did I use AI help? Yes — to check the greedy rule and boundary cases.

Most useful question: “Does a talk starting exactly when cleanup finishes count as compatible?”

What I learned: The correct test is `start >= available_at`, not `start > available_at`. Equal times should be accepted.

### 4. My Revision

I tracked each talk's original index before sorting, because sorting changes positions. I also stored the earliest next available time rather than just the previous finish time. This makes the cleanup constraint explicit.
