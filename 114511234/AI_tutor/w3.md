#### 2. My Initial Approach — Before AI Help

**My approach:** 寫兩個檢查用的輔助方法：`NisValid` 檢查帳號是否在 1 到 n 之間，`MisValid` 檢查餘額是否足夠。`transfer`、`deposit`、`withdraw` 先用 `and` 串起需要的檢查，都通過才更新 `balance` 並回傳 `True`，否則回傳 `False`。帳號從 1 開始編，所以索引用 `account - 1`。

#### 3. AI Tutor Help

- ☐ No — I solved it independently
- ☑ Yes — I received one or more hints

**The most useful hint/question from AI was:** AI 直接指出兩個語法錯誤：在 class 裡呼叫 `NisValid`、`MisValid` 都漏了 `self.`；呼叫 `MisValid` 時只傳了帳號、漏了 `money`，執行時會出現 `TypeError: missing 1 required positional argument`。AI 檢查後認為邏輯沒有問題。

**It helped me realize that:** 在 class 裡呼叫自己的方法一定要經過 `self`，Python 不會像 C++ 那樣自動找到 `this` 的成員，我連續三題都犯了這個錯；呼叫時的參數個數也要跟定義一致。

#### 4. My Revision

- ☐ No
- ☑ Yes

**What did you change, and why?** 補上所有的 `self.`，並把 `MisValid(account1)` 改成 `MisValid(account1, money)`。修完就通過了，判斷邏輯沒有改。之後 AI 講解了可以改進的寫法：`if 條件: return True else: return False` 可以直接 `return 條件`；帳號檢查可以用連續比較 `1 <= account <= len(self.balance)`；`if` 的條件不需要加括號；命名改用 snake_case。

#### 6. One-Minute Reflection

**What idea from the OCW lecture did you transfer to this new problem?** 防禦性程式設計：先檢查帳號和餘額，全部合法才動到資料。題目規定不合法時回傳 `False`，這是 L7 說的「回傳錯誤值」那種做法；如果是自己設計的 Python 程式，L7 會建議改成 `raise ValueError`。
