### 1. Today's Challenge

**Core concept from today's OCW lecture:**

用 `Digraph` / `Graph` class 表示圖（`Graph` 繼承 `Digraph`，加邊時順便加反方向），用 BFS 找邊數最少的路徑，用 DFS 搭配 visited 避免在環上無限迴圈。

**AI-generated coding challenge title:** 捷運最少站數（Fewest Stops）

- `Digraph`：`add_node`、`add_edge`、`children_of`；節點重複或邊的端點不存在時 `raise ValueError`
- `Graph(Digraph)`：雙向的邊
- `fewest_stops(graph, start, end)`：回傳經過站數最少的路線（站名 list），到不了或站名不存在時回傳 `None`
- `reachable(graph, start, end)`：用 DFS 判斷到不到得了，圖上有環也不能無限迴圈

**My approach:**

用 BFS，一層一層往外找，第一次走到終點時就是站數最少的路線。queue 裡放的是整條路徑，每次取出一條路徑，對最後一站的每個鄰居複製出一條新路徑放回 queue。

**The most useful hint/question from AI was:**

「BFS 找到終點時，只知道『到了』。要印出完整路線，最省記憶體的方法是？」我選了 queue 放整條路徑，AI 說明這個做法可以用，但不是最省記憶體的。

**It helped me realize that:**

1. 用 `parent` dict 記住每一站是從哪一站來的，最後從終點往回走就能還原路徑，不需要在 queue 裡複製一整條路徑。
2. `parent` 同時也是 visited：一站第一次被放進 queue 時就記錄 parent，之後不會再放進去，所以 BFS 是 O(V + E)。

### 4. My Revision

- [ ] No
- [x] Yes

**What did you change, and why?**

1. queue 裡只放站名，另外用 `parent` dict 記住上一站，找到終點後往回走再 `[::-1]` 反轉。
2. queue 用 `collections.deque` 的 `popleft()`，它是 O(1)；`list.pop(0)` 要把後面所有元素往前搬，是 O(n)。
3. `reachable` 用 DFS，並傳一個 `visited` set，預設值寫 `None`，進函數才建立新的 set（W10 學到的預設值陷阱）。
4. 起點或終點不在圖上時直接回傳 `None`，不讓程式 `KeyError`。

### 5. Verification

**My final program:**（完整程式見 `w11.py`）

```python
from collections import deque


def fewest_stops(graph, start, end):
    if not graph.has_node(start) or not graph.has_node(end):
        return None
    parent = {start: None}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node == end:
            path = []
            while node is not None:
                path.append(node)
                node = parent[node]
            return path[::-1]
        for nxt in graph.children_of(node):
            if nxt not in parent:
                parent[nxt] = node
                queue.append(nxt)
    return None


def reachable(graph, start, end, visited=None):
    if visited is None:
        visited = set()
    if start == end:
        return True
    visited.add(start)
    for nxt in graph.children_of(start):
        if nxt not in visited and reachable(graph, nxt, end, visited):
            return True
    return False
```
