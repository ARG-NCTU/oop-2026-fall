### ② My Misconception

**Before: I thought…**

`a + b` 是「把 b 加到 a 上面」，所以 `__add__` 裡面應該去改 `self` 的 attribute，改完 `a` 就變成相加後的結果。

**Now: I understand…**

`a + b` 只是 `a.__add__(b)` 的另一種寫法，會得到什麼完全看 `__add__` 回傳什麼。課堂的 `Fraction.__add__` 是算出新的分子、分母後 `return Fraction(top, bott)`，回傳一個新的 object，`a` 和 `b` 都不會變。這和 int 的行為一致：`x + 1` 不會改到 `x`。如果在 `__add__` 裡修改 `self`，`c = a + b` 之後 `a` 也被改掉，會是很難發現的 bug。

### 5. Verification

**My final program:**（見 `w4.py`）

```python
class Time(object):
    def __init__(self, hour, minute):
        assert type(hour) == int and type(minute) == int, "ints not used"
        assert 0 <= hour <= 23 and 0 <= minute <= 59, "time out of range"
        self.total = hour * 60 + minute

    def get_hour(self):
        return self.total // 60

    def get_minute(self):
        return self.total % 60

    def __str__(self):
        return "%02d:%02d" % (self.get_hour(), self.get_minute())

    def __add__(self, minutes):
        new_total = (self.total + minutes) % (24 * 60)
        return Time(new_total // 60, new_total % 60)

    def __sub__(self, other):
        return (self.total - other.total) % (24 * 60)

    def __float__(self):
        return self.total / 60

    def __eq__(self, other):
        return self.total == other.total
```
