### ② My Misconception

**Before: I thought…**

1. `3 + "hi"` 不能這樣加，所以是 syntax error。
2. int 除以 int，而且剛好整除，結果應該還是 int，所以 `6 / 3` 是 `2`。

**Now: I understand…**

1. `3 + "hi"` 的形狀是合法的 `<object> <operator> <object>`，所以 syntax 沒有錯；錯的是 int 和 str 配上 `+` 沒有意義，屬於 static semantic error。真正的 syntax error 是像 `"hi"5` 這種連形狀都不對的寫法。
2. Python 的 `/` 永遠回傳 float，`6 / 3` 是 `2.0`。只有 `+`、`-`、`*` 才是 int 配 int 得到 int。
