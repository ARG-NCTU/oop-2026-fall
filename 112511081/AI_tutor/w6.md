## Part B: LeetCode-style Lecture Code Transfer

### 1. Today's Challenge

**Core concept from today's OCW lecture:**

數運算次數來分析效率、Big-O 只看最高次項，以及課堂上比較的 linear search 與巢狀迴圈 O(n²) 的寫法（例如判斷兩個 list 有沒有交集）。

**AI-generated coding challenge title:** 兩數相加（Pair Sum）

- `pair_sum(nums, target)`：list 裡如果有兩個「不同位置」的數字相加等於 `target`，回傳 `True`，否則回傳 `False`
- 同一個位置不能用兩次，但數值相同、位置不同的兩個數可以配對（例如 `[5, 5]`，target 是 10）
- 寫出至少兩種做法，並分析各自的複雜度

### 2. My Initial Approach — Before AI Help

**My approach:**

先排序，再用兩個指標從左右兩端往中間夾：

1. `s = sorted(nums)`，`i` 指向最左邊，`j` 指向最右邊。
2. `s[i] + s[j]` 等於 target 就回傳 `True`；太小就 `i += 1`；太大就 `j -= 1`。
3. `i` 和 `j` 相遇時還沒找到，就回傳 `False`。

複雜度：排序是 O(n log n)，夾的過程是 O(n)，整體是 O(n log n)，比兩層迴圈全部配對的 O(n²) 好。

### 5. Verification

**My final program:**（完整程式見 `w6.py`）

```python
def pair_sum_sorted(nums, target):
    s = sorted(nums)
    i, j = 0, len(s) - 1
    while i < j:
        total = s[i] + s[j]
        if total == target:
            return True
        elif total < target:
            i += 1
        else:
            j -= 1
    return False


def pair_sum_fast(nums, target):
    seen = set()
    for x in nums:
        if target - x in seen:
            return True
        seen.add(x)
    return False
```
