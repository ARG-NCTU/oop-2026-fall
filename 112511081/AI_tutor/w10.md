## Part B: LeetCode-style Lecture Code Transfer

### 1. Today's Challenge

**Core concept from today's OCW lecture:**

把問題寫成遞迴（決策樹），發現同樣的子問題被重複計算後，用 dict 當 memo 記住答案（課堂上的 `fastFib` 和 `fastMaxVal`）。

**AI-generated coding challenge title:** 最少硬幣數（Fewest Coins）

- `min_coins(coins, amount)`：用 `coins` 裡的面額（每種可以用無限次）湊出 `amount`，最少要幾枚
- 湊不出來回傳 `None`
- 例：`coins = [1, 3, 4]`、`amount = 6`，答案是 2（3 + 3）；貪婪法先拿 4 會得到 4 + 1 + 1，是 3 枚

### 2. My Initial Approach — Before AI Help

**My approach:**

遞迴試每一種硬幣：`f(n) = 1 + min(f(n - c))`，對每個面額 `c` 都試一次，`f(0) = 0`，最後再加上 memo。

**What did you change, and why?**

1. 湊不出來時回傳 `None`，取 min 時加上 `sub is not None` 的檢查。
2. memo 的預設值寫成 `memo=None`，進函數後才建立新的 `{}`。如果寫 `memo={}`，這個 dict 只會在定義函數時建立一次，之後所有呼叫都共用同一個，換了 `coins` 之後會拿到上一次的舊答案。這也是 Part A ④ 我不確定的地方。
3. 另外寫一個不加 memo 的版本，用來比對小的測資；也寫了貪婪版，確認它在 `[1, 3, 4]` 湊 6 時是錯的。

### 5. Verification

**My final program:**（完整程式見 `w10.py`）

```python
def min_coins(coins, amount, memo=None):
    if memo is None:
        memo = {}
    if amount == 0:
        return 0
    if amount < 0:
        return None
    if amount in memo:
        return memo[amount]
    best = None
    for c in coins:
        sub = min_coins(coins, amount - c, memo)
        if sub is not None and (best is None or sub + 1 < best):
            best = sub + 1
    memo[amount] = best
    return best
```
