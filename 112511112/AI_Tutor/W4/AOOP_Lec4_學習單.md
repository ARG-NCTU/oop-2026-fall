## ② My Misconception

**Before: I thought…**

return 基本就是最優解，幾乎永遠比 print 更好。

---

**Now: I understand…**

return 與 print 的用途不同。

- return 用於回傳資料供其他程式碼繼續運算與使用。
- print 用於顯示資訊、除錯與觀察程式執行結果。
- 它們不是互相取代的關係，而是解決不同需求的工具。
