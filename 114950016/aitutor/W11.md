### ② My Misconception

**Before: I thought…**

我原本把「函式執行後有顯示東西」和「函式有回傳值」當成同一回事，常以為在函式裡用 `print()` 印出答案，就可以拿那個答案去做後續運算。

**Now: I understand…**

`print()` 負責顯示內容，`return` 才會把值交回呼叫函式的地方。若想讓另一個函式利用結果，應使用 `return`。同時，每次呼叫函式會建立自己的作用域；區域變數與外面同名，也不代表外部數值會跟著被修改。

### Problem Statement

給定一串商品價格 `prices`，以及折扣率 `discount`，計算折扣後的總價。價格皆為非負整數，折扣率為 0 到 100 的整數百分比。先寫獨立函式檢查每筆價格是否有效，再寫函式計算總額，最後寫主要函式計算折扣價。如果任一價格為負數，回傳 `None`。輸出可為浮點數。

### Input / Output Specification

- 函式介面：`checkout(prices, discount)`。

### Constraints

- 每項價格為整數，測試可能包含負值。
- `0 ≤ discount ≤ 100`。
- 不修改輸入串列，也不使用全域變數。

### 4. My Revision

- 新增 `valid_prices` 專門驗證價格。
- 新增 `sum_prices` 專門計算總額。
- `checkout` 呼叫兩個函式並回傳最終金額，而不是只 `print` 出數字。
- 遇到負數直接回傳 `None`，避免把不合法資料當成正常總額。

### Final Program

```python
def valid_prices(prices):
    """Return True if every price is nonnegative."""
    for price in prices:
        if price < 0:
            return False
    return True


def sum_prices(prices):
    """Return the sum of all prices."""
    total = 0
    for price in prices:
        total += price
    return total


def checkout(prices, discount):
    """Return discounted total, or None for invalid prices."""
    if not valid_prices(prices):
        return None
    total = sum_prices(prices)
    return total * (100 - discount) / 100
```

### Why the Solution Works

`valid_prices` 逐一檢查每個價格，只要有負數便回傳 False，主函式會回傳 `None`。當全部價格合法時，`sum_prices` 把所有商品價格加總，接著乘以 `(100-discount)/100`，正好得到指定的折扣後金額。每個函式只負責一個明確工作，因此容易分開測試。

### Complexity

令 n = `len(prices)`。驗證函式最多掃描 n 個元素，總和函式也掃描 n 個元素，故總時間為 **O(n)+O(n)=O(n)**；除了固定數量的變數，未配置與 n 同比例的儲存空間，因此額外空間 **O(1)**。
