## Part B: LeetCode-style Lecture Code Transfer

### 1. Today’s Challenge

**Core concept from today’s OCW lecture:**

利用排序資料進行二分搜尋，每次排除約一半候選範圍；使用索引而非串列切片，避免額外的複製成本。

**AI-generated coding challenge title:** 找出排序串列中目標數字第一次出現的位置（Find First Occurrence in a Sorted List）。

### Problem Statement

給定一個已按非遞減順序排列的整數串列 `nums`，以及整數 `target`，請回傳 `target` 第一次出現的索引；如果不存在，回傳 `-1`。

串列可能包含重複數字。請使用二分搜尋完成，不可使用 `list.index()` 或串列切片。不能修改原始串列。

### Input / Output Specification

- 輸入：`nums`（已排序整數串列）及 `target`（目標整數）。
- 輸出：目標第一次出現的索引；不存在時回傳 `-1`。
- 函式介面：`first_occurrence(nums, target)`。

### Constraints

- 0 ≤ len(nums) ≤ 100000。
- -1000000 ≤ nums[i], target ≤ 1000000。
- `nums` 依非遞減順序排列，允許重複元素。
- 不可修改輸入串列。

### Examples

**Example 1**

```text

Output: 1
```

數字 2 最早出現在索引 1，即使後面還有其他 2，也要回傳最左邊的位置。

**Example 2**

```text
Input:  nums = [1, 3, 5, 7], target = 4
Output: -1
```

串列中沒有目標數字 4。

**Example 3**

```text

Output: 0
```

全部元素都相同時，第一次出現的位置為索引 0。

### 2. My Initial Approach — Before AI Help

我一開始想到用 `for` 迴圈從左到右逐一找 `target`，找到就立即回傳索引。這樣可以保證找到第一次出現的位置，但最壞情況必須掃描所有元素，所以是 O(n)。

因為題目已經給了排序串列，我想用講義的二分搜尋將複雜度降低到 O(log n)。不過一般二分搜尋找到相同值就直接回傳，遇到重複值時，可能回傳中間位置而不是第一次出現的位置。

**The most useful hint/question from AI was:**

如果 `nums[mid] == target`，是否就能確定這是最左邊的位置？既然左邊還可能有相同數字，要怎麼縮小搜尋範圍又不遺失目前找到的答案？

**It helped me realize that:**

找到目標時不能立刻回傳，而是先把 `mid` 記為候選答案，再把右邊界改成 `mid - 1`，繼續往左找。如果找到更左邊的目標，就更新答案；沒有的話保留原本答案。

### 4. My Revision

- 將逐一搜尋改成使用 `low`、`high`、`mid` 的二分搜尋。
- 增加 `answer = -1`，記錄目前找到的最左邊候選位置。
- 當 `nums[mid] == target` 時先記下 `mid`，再繼續搜尋左半邊。
- 不使用切片，讓每次搜尋只做固定數量的操作。

### Final Program

```python
def first_occurrence(nums, target):
    low = 0
    high = len(nums) - 1
    answer = -1

    while low <= high:
        mid = (low + high) // 2
        if nums[mid] == target:
            answer = mid
            high = mid - 1
        elif nums[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return answer
```

### Why the Solution Works

當 `nums[mid] < target` 時，因為串列已排序，`mid` 與其左側都不可能是答案，所以將 `low` 移到 `mid + 1`。當 `nums[mid] > target` 時，排除 `mid` 與其右側。當兩者相等時，先記下候選答案，再繼續往左側尋找是否有更早的位置。因此最後保留下來的答案就是目標第一次出現的索引；若始終找不到，就回傳 `-1`。

### Complexity

令 n = len(nums)。

- 最壞時間複雜度：**O(log n)**（n ≥ 2）。每輪把候選範圍縮小約一半，而且每輪只做 O(1) 工作；含空串列的嚴格表達可寫 O(log(n+1))。
- 額外空間複雜度：**O(1)**，只使用 `low`、`high`、`mid` 和 `answer` 等固定數量變數。
- 與講義切片版本不同，本題不複製子串列，因此沒有額外的 O(n) 複製成本。
