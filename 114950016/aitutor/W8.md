### 1. Today’s Challenge

**Core concept from today’s OCW lecture:**

利用 Merge Sort 的合併（merge）步驟，從兩份已排序串列的開頭比較元素，每次取出較小者，避免重新排序或使用巢狀迴圈逐一比較。

**AI-generated coding challenge title:** 合併兩份已排序名單並去除重複數字（Merge Two Sorted Lists Without Duplicates）。

### Problem Statement

給定兩個已經依非遞減順序排列的整數串列 `A` 和 `B`，請將兩份資料合併成一個遞增排列的串列，並移除重複數字，使每個不同的數字只出現一次。

兩份串列中都可能有重複元素，也可能有相同的數字出現在不同串列。請利用兩個索引逐步合併，不可使用 `sorted()`、`sort()` 或 `set()`，也不能修改原始串列。

### Input / Output Specification

- 輸入：`A`、`B`，兩個已按非遞減順序排列的整數串列。
- 輸出：一個遞增排列且不含重複元素的新串列。
- 函式介面：`merge_unique(A, B)`。

### Constraints

- 0 ≤ len(A), len(B) ≤ 100000。
- -1000000 ≤ A[i], B[j] ≤ 1000000。
- 兩個輸入串列皆已排序，允許重複元素。
- 不可修改輸入串列。

### Examples

**Example 1**

```text
Input:  A = [1, 2, 2, 5], B = [2, 3, 5, 7]
Output: [1, 2, 3, 5, 7]
```

合併時數字 2 和 5 雖然出現不只一次，但輸出只保留一份。

**Example 2**

```text
Input:  A = [], B = [1, 1, 4]
Output: [1, 4]
```

其中一份串列為空時，仍要正確處理另一份串列內部的重複數字。

**Example 3**

```text
Input:  A = [-3, -1, 2], B = [-2, -1, 2, 2]
Output: [-3, -2, -1, 2]
```

即使包含負數，仍然只需要依大小比較並依序加入結果。

**The most useful hint/question from AI was:**

如果 `A[i]` 和 `B[j]` 一樣，兩個索引要怎麼移動？如果兩份串列中的重複值連續出現，是否只需要檢查結果串列最後一個元素，就能避免重複加入？

**It helped me realize that:**

因為每次選出的數字都不會小於前一個已加入結果的數字，所以重複數字一定會和結果最後一個元素相同。只要在 `append` 前比較 `result[-1]`，就不必從頭搜尋結果串列。另外，當兩邊數字相同時可以同時前進，避免重複處理。

### 4. My Revision

- 不將兩份串列直接接起來重新排序，改成兩個索引同步合併。
- 若 `A[i] < B[j]`，取 `A[i]`；若 `A[i] > B[j]`，取 `B[j]`；兩者相等時，取其中一個值並將兩個索引都往後移。
- 每次要加入結果前，先判斷結果是否為空，或最後一個值是否與目前數字不同。
- 當其中一份串列先走完，繼續處理另一份串列的剩餘元素。

### Final Program

```python
def merge_unique(A, B):
    i = 0
    j = 0
    result = []

    while i < len(A) and j < len(B):
        if A[i] < B[j]:
            value = A[i]
            i += 1
        elif A[i] > B[j]:
            value = B[j]
            j += 1
        else:
            value = A[i]
            i += 1
            j += 1

        if not result or result[-1] != value:
            result.append(value)

    while i < len(A):
        if not result or result[-1] != A[i]:
            result.append(A[i])
        i += 1

    while j < len(B):
        if not result or result[-1] != B[j]:
            result.append(B[j])
        j += 1

    return result
```

### Why the Solution Works

因為 `A` 和 `B` 都已排序，尚未處理的最小值一定在 `A[i]` 或 `B[j]`。每次比較兩個位置並選出較小值，就能確保加入結果的順序不會變亂。若兩邊相等，兩個位置的數字相同，處理一次並同時前進即可。

對每次選出的數字，都只與 `result` 最後一個元素比較。由於選出數字的順序是非遞減的，重複值只可能和最後一個已加入的值相同，因此這樣就能排除所有重複數字。當其中一份串列結束後，依序處理另一份剩下的元素，最後便能得到完整且不重複的遞增串列。

### Complexity

令 n = len(A)，m = len(B)。

- 最壞時間複雜度：**O(n + m)**。每次迴圈至少會讓一個索引往前移，每個元素最多被檢查固定次數，因此兩個串列總共只需線性工作量。
- 包含回傳結果的額外空間：**O(n + m)**。最壞情況下所有數字都不重複，結果需要存放 n + m 個元素。
- 若不計回傳結果，輔助空間：**O(1)**，只使用索引 `i`、`j`、暫存值等固定數量變數。
- 與課堂 Merge Sort 的完整排序 O(N log N) 不同，本題輸入本來就各自排序好了，只需執行一次 merge，所以是線性時間。
