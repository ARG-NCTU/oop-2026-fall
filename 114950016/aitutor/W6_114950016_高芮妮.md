### 1. Today’s Challenge

**Core concept from today’s OCW lecture:**

**AI-generated coding challenge title:** 找出有重複數字的位置（Find Duplicate Positions）。

### Problem Statement

給定一個整數串列 `nums`，請找出所有「在其他位置至少還出現過一次」的元素索引，並依照索引由小到大回傳。

例如 `nums = [4, 7, 4, 9, 7]`，數字 4 出現在索引 0、2，數字 7 出現在索引 1、4，因此結果為 `[0, 1, 2, 4]`。

請使用課堂學過的串列、迴圈、條件判斷與比較運算完成，不使用集合、字典或排序函式。

### Input / Output Specification

- 輸入：`nums`，整數串列。
- 輸出：所有有重複值的元素索引，按索引遞增排列。
- 函式介面：`duplicate_positions(nums)`。

### Constraints

- 0 ≤ len(nums) ≤ 1000。
- -100000 ≤ nums[i] ≤ 100000。
- 不可修改原始輸入串列。
- 相同數字出現超過兩次時，所有對應索引都要回傳。

### Examples

**Example 1**

```text
Input:  [4, 7, 4, 9, 7]
Output: [0, 1, 2, 4]
```

數字 4 和 7 都出現超過一次，9 只有出現一次。

**Example 2**

```text
Input:  [1, 2, 3, 4]
Output: []
```

沒有任何重複數字。

**Example 3**

```text
Input:  [5, 5, 5]
Output: [0, 1, 2]
```

三個位置的數字相同，所以三個索引都要回傳。

### 2. My Initial Approach — Before AI Help

我打算用兩層迴圈：外層選擇目前要檢查的索引 i，內層逐一比較其他位置 j。如果 i 和 j 不同，而且兩個位置的數字一樣，就代表 nums[i] 有重複。這時把 i 加入答案，然後用 `break` 停止內層迴圈，避免同一個索引被加入很多次。

這個做法和講義的 `isSubset` 範例有相似的地方，都是針對外層的每個元素，逐一檢查內層元素是否符合條件。

**The most useful hint/question from AI was:**

如果直接比較 `nums[i] == nums[j]`，當 `i == j` 時會發生什麼事？找到第一個重複值之後，是否還需要繼續檢查剩下的位置？

**It helped me realize that:**

每個元素都一定等於自己，因此必須先排除 `i == j`，不然所有索引都會被錯誤地加入結果。另外，只要找到一個不同位置的相同數字，就已經符合題目要求，可以直接 `break`，減少不必要的比較。

### 4. My Revision

- 增加 `if i == j: continue`，避免與自己比較。
- 找到第一個重複位置後就 `break`，避免同一索引重複加入。
- 外層由小到大遍歷索引，讓結果自然保持遞增。
- 保留原本的 `nums`，只把符合條件的索引加入新的結果串列。

### Final Program

```python
def duplicate_positions(nums):
    result = []

    for i in range(len(nums)):
        for j in range(len(nums)):
            if i == j:
                continue
            if nums[i] == nums[j]:
                result.append(i)
                break

    return result
```

### Why the Solution Works

對每個索引 i，內層會檢查所有其他位置 j。若找到 `i != j` 且 `nums[i] == nums[j]`，就表示該數字確實在另一個位置出現，因此將 i 加入答案是正確的。若完全找不到相同數字，i 就不會加入。由於找到後立即停止內層搜尋，每個 i 最多只會加入一次；外層又按照索引順序執行，因此結果不會重複且保持遞增。

### Complexity

令 n = len(nums)。

- 最壞時間複雜度：**O(n²)**。當所有數字都不重複時，每個索引都要檢查其他 n−1 個位置，總共約 n(n−1) 次有效比較。
- 包含輸出結果的額外空間：**O(n)**，因為最多回傳 n 個索引。
- 若不計輸出結果，輔助空間：**O(1)**，只需要固定數量的變數。
