## Part B: LeetCode-style Lecture Code Transfer

### 1. Today’s Challenge

**Core concept from today’s OCW lecture:**

使用數值函數的單調性建立二分搜尋區間，每次縮小一半，並根據 epsilon 判斷近似解是否足夠接近。

**AI-generated coding challenge title:** 近似求任意實數的立方根（Approximate Cube Root with Bisection）

### Problem Statement

輸入一個實數 `x` 與正的容許誤差 `epsilon`，回傳一個浮點數 `guess`，使 `abs(guess**3-x) < epsilon`。需要處理正數、負數、0，以及介於 -1 到 1 的數字；不得直接使用三次根號運算或數學套件。

### Input / Output Specification

- 輸入：實數 `x` 和浮點數 `epsilon`。
- 輸出：滿足立方值誤差條件的浮點數。
- 函式介面：`cube_root_bisect(x, epsilon)`。

### Constraints

- `-1000000 ≤ x ≤ 1000000`。
- `0 < epsilon ≤ 0.1`。
- 只用比較、迴圈和基本四則運算；浮點誤差依指定 epsilon 判定。

### Examples

**Example 1**

```text
Input:  x=27, epsilon=0.01
Output: 接近 3，且 |guess³-27| < 0.01
```

**Example 2**

```text
Input:  x=0.125, epsilon=0.0001
Output: 接近 0.5，且 |guess³-0.125| < 0.0001
```

**Example 3**

```text
Input:  x=-8, epsilon=0.001
Output: 接近 -2，且 |guess³+8| < 0.001
```

### 4. My Revision

- 先對 x 取絕對值以確保搜尋單調方向固定。
- 將上界改成 `max(1, abs(x))`，涵蓋 0 到 1 的值。
- 用立方值與目標值的誤差決定何時停止，並在結果加上負號。

### Final Program

```python
def cube_root_bisect(x, epsilon):
    if x == 0:
        return 0.0
    a = abs(x)
    low = 0.0
    high = max(1.0, a)
    guess = (low + high) / 2.0
    while abs(guess ** 3 - a) >= epsilon:
        if guess ** 3 < a:
            low = guess
        else:
            high = guess
        guess = (low + high) / 2.0
    if x < 0:
        return -guess
    return guess
```

### Why the Solution Works

對 a=abs(x)，立方函數在非負範圍嚴格遞增，而且 a 的立方根必定位於 `[0,max(1,a)]`。每輪比較 `guess³` 與 a，保留包含根的那一半區間，因此不會丟失答案。演算法找到符合 epsilon 的 guess 後，再依 x 的符號回傳。

### Complexity

以數值區間寬度 H 與欲達到的精度為依據，每輪將區間減半，因此迭代次數呈對數成長。就固定的輸入範圍與正的 epsilon 而言，時間與所需精度相關；額外空間 **O(1)**。此處不直接將時間寫成 O(log n)，因為輸入不是長度 n 的串列。
