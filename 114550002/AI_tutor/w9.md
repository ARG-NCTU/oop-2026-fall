## ② My Misconception
### Before: I thought…

If a recursive algorithm has an exponential time complexity of $O(2^n)$, its auxiliary space complexity (the memory required for the call stack) must also be exponential, $O(2^n)$, because the program executes $O(2^n)$ total recursive function calls.

### Now: I understand…

Because stack frames are pushed on call and popped on return, the stack only ever holds the active path from the root to the current node (the height/depth of the tree).
