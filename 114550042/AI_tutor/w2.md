### ② My Misconception

Before: I thought…

我原本對 Python 字典判定 Key 的 Hash 機制不甚熟悉，直覺認為只要資料型別不同（例如 `int` 的 `1`、`float` 的 `1.0` 與 `bool` 的 `True`），在底層就會被區分開來儲存為三個獨立的鍵。

⸻

Now: I understand…

現在我理解了 Python 雜湊的核心鐵律（Hash Invariant）：只要兩物件在數值相等（`a == b` 為 True），其計算出的雜湊值就必須完全相同（`hash(a) == hash(b)`）。在字典中，當兩個 Key 的 Hash 相同且值相等時，Python 會判定其為同一 Key 並覆寫 Value，因此 `1`、`1.0` 與 `True` 在字典中會互相覆寫，最終只會保留一個鍵值對。

AI-generated coding challenge title:

Nested Dictionary Depth-Weighted Sum（巢狀字典深度加權總和）

```python
def nested_depth_sum(d: dict[str, int | dict], depth: int = 1):
    total = 0
    for v in d.values():
        if isinstance(v, dict):
            total += nested_depth_sum(v, depth + 1)
        else:
            total += v * depth
    return total
```
