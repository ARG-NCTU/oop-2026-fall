1. **一般圖的模型與繼承設計**：無向圖 `Graph` 應繼承自 `Digraph`（並在加入邊時同時加入正反兩條有向邊），才符合里氏替換原則（LSP）；一般有環圖的 DFS 最短路徑不能使用全域永久 `visited` 擋路，否則長繞路先標記節點會阻擋較短路徑。
2. **BFS 適用條件與 `visited` 標記時機**：標準 BFS 只保證「最少邊數（hop count）」最短，不適用於邊權重不等的加權圖；且無權重 BFS 應在**放入佇列（Enqueue）當下**立刻將鄰居加入 `visited`（代表已發現並鎖定最短距離），才能避免鑽石圖中重複塞入佇列造成的時間與空間爆炸。
3. **有向圖與無向圖找環的差異**：無向圖只需排除直接父節點並看是否碰到 `visited`，但有向圖（如無環 DAG `A->B, A->C, B->C`）中碰到已結束的 `visited` 節點不代表有環，必須區分「目前仍在遞迴路徑堆疊上」與「已完成」的節點。

AI-generated coding challenge title:

Security Terminal Unlock（數字終端機的最少解鎖步數）

```python
from collections import deque


def security_terminal_unlock(start: int, target: int, limit: int, forbidden: list[int]):
    """
    This function finds the minimum number of steps required to unlock a security terminal.
    """
    # convert to set for O(1) lookups
    forbidden_set = set(forbidden)

    # if the start or target is forbidden, return -1
    if start in forbidden_set or target in forbidden_set:
        return -1

    queue = deque([(start, 0)])  # (current number, steps taken)
    visited = set([start])

    while queue:
        current, steps = queue.popleft()

        if current == target:
            return steps

        # possible next moves
        for next_num in (current + 1, current - 1, current * 2):
            # check if the next number is within limits and not forbidden or visited
            if 0 <= next_num <= limit and next_num not in forbidden_set and next_num not in visited:
                visited.add(next_num)
                queue.append((next_num, steps + 1))

    return -1
```
