AI-generated coding challenge title:

Coupon Collector Simulation（集齊整套盲盒的期望抽數模擬）

```python
import random


def coupon_collector_simulation(n: int, trials: int, seed: int = 0) -> float:
    """
    Simulates the coupon collector's problem.

    Args:
    n (int): The number of unique coupons.
    trials (int): The number of simulation trials to run.

    Returns:
    float: The average number of coupons needed to collect all unique coupons.
    """
    random.seed(seed)

    coupons_needed = 0

    for _ in range(trials):
        collected = set()
        while len(collected) < n:
            new_coupon = random.randint(1, n)
            collected.add(new_coupon)
            coupons_needed += 1

    return coupons_needed / trials
```
